# {Фича} — открытые вопросы

Единственный реестр нерешённых решений по фиче «{Название}». Документы фичи ссылаются сюда,
а не носят собственные списки вопросов.

Идентификаторы (`{ПРЕФИКС}-Q1`, …) **стабильны и только дополняются** — не переиспользуются
и не перенумеровываются. Места, затронутые вопросом, помечены `⚠{ПРЕФИКС}-Qx` в [index.md](index.md).
