# Совместный доступ — открытые вопросы

Единственный реестр нерешённых решений по фиче «Совместный доступ». Документы фичи ссылаются
сюда, а не носят собственные списки вопросов.

Идентификаторы (`SHARE-Q1`, …) **стабильны и только дополняются** — не переиспользуются
и не перенумеровываются. Места, затронутые вопросом, помечены `⚠SHARE-Qx` в [index.md](index.md).
