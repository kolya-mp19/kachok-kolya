# Динамика прогресса — открытые вопросы

Нерешённые решения по фиче «Динамика прогресса». Затронутые места
[спеки](./index.md) помечены ссылкой на идентификатор вопроса.
После решения правило записывается в спеку, маркер и строка удаляются;
опустевший реестр удаляется целиком.

| # | Вопрос | Последствия, пока не решён |
|---|---|---|
| **PROGRESS-Q1** | **Несколько значений собственного веса на одну дату.** Как обрабатывается новое отличающееся значение на дату, для которой уже есть запись, включая сочетание ручного ввода и ответа в итогах цикла: сохраняются несколько записей, предлагается явная замена или используется другой согласованный вариант? Нужно определить результат сохранения и отображение на графике без молчаливой потери предыдущего ввода | **Несущий для совпадающих дат в E025/E027:** до решения нельзя однозначно принять сохранение и представление такого случая. Допустимость ручного ввода с любой датой по R17.2 не меняется |
