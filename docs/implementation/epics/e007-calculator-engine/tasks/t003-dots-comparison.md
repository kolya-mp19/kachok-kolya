# E007-T003. Рассчитывать сравнение по DOTS

## Что сделать

**Что даёт:** пользовательский сценарий получает третью независимую формулу для всей сессии.

DOTS добавляется в существующее чистое ядро TypeScript через `formula: 'dots'`.
Согласованный стек и общий контракт закреплены в [PRD](../prd.md).
Локальные E004/E005, E006-T001 и расчётные T001/T002 приняты. Внешние задачи
E003 и E006-T002/T003 локальное исполнение не блокируют; внешние интеграции
и выпуск отложены.

Локальных блокеров нет. Источник статуса — реестр задач в карточке эпика.

## Критерии готовности

- [x] Подтверждён первичный источник DOTS, уравнения и коэффициенты обоих полов, независимые контрольные значения; чужой бытовой калькулятор не единственный эталон.
- [x] При смене формулы пересчитывается весь рейтинг, отсутствующие и неконечные величины обрабатываются по общему контракту.
- [x] Формула проверяется без сервера и UI и не добавляет ограничений положительного собственного веса.

## Проверка

Публичная граница проверки — «карточки → `calculateComparison` → рейтинг»,
согласованная при T001. [Четыре теста DOTS](../../../../../tests/calculator-dots.test.mjs)
запускаются через `node --test tests/calculator-dots.test.mjs`, без UI и сервера.
Проверяются четыре независимых протокольных эталона обоих полов, переключение
между формулами, изменение мест и лидеров, неизменность входа, неполные карточки,
переполнение формулы и итога, экстраполяция вне авторских диапазонов без подмены веса.

Проверка типов — `npm run typecheck`; полный чистый снимок проверяется по
[E006-T001](../../e006-delivery-foundation/checks.md). Chromium используется из общего
пользовательского кэша. Итоговый review сравнивает задачу с базой `8239e87` отдельно
по соглашениям и требованиям. Покрытие приёмки эпика: позиции 1, 3, 7–8 в части DOTS.

## Результат и продолжение

Реализован DOTS для обоих полов в существующем контракте расчёта.
[Справка DOTS](../dots-reference.md) содержит первичный источник Tim Konertz,
независимые официальные значения BVDK/BGKV и отличие продуктовой экстраполяции
от спортивного ограничения диапазона. Рейтинг полностью пересчитывается при смене
формулы; коэффициент и итог не округляются. Визуальный интерфейс относится к E008.
Полный прогон чистого дерева `8a210633b3b1b10875904b218bbb17ee78e05a5e`
успешен: установка по lockfile, Chromium из общего кэша без скачивания,
синтетическая PostgreSQL, Prisma, форматирование, типы, сборка, 79/79 тестов
без пропусков и очистка ресурсов. Итоговый независимый review относительно
`8239e87`: Standards — 0 замечаний, Spec — 0 замечаний. Относительные ссылки
документации проверены. Последующие изменения результата и реестров — только документация.
Общая приёмка трёх формул и передача контрольных примеров выполнены отдельно
в [E007-T004](./t004-ranking-boundaries.md).
