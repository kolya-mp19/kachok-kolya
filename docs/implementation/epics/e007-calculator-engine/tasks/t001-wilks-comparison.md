# E007-T001. Рассчитывать сравнение по оригинальному Уилксу

## Что сделать

**Что даёт:** независимое ядро принимает карточки и возвращает лучшие попытки, коэффициенты, итоги и рейтинг по формуле по умолчанию.

Расчётное ядро — чистые функции TypeScript в клиентском контексте калькулятора.
Согласованные решения S01 перенесены в [PRD](../prd.md); локальные E004, E005 и
E006-T001 приняты. Внешние задачи E003 и E006-T002/T003 локальное исполнение не
блокируют. Внешние интеграции и выпуск отложены.

Локальных блокеров нет. Источник статуса — реестр задач в карточке эпика.

## Критерии готовности

- [x] До вычислений проверены первичные публикации оригинального Уилкса, коэффициенты обоих полов и независимые контрольные примеры; Wilks-2 не подменяет редакцию.
- [x] Точка и запятая равнозначны; отсутствующие и недопустимые значения не блокируют остальные карточки; лучшая попытка доступна без пола и собственного веса.
- [x] Итоги и места считаются до округления, идентичность и порядок карточек сохранены; расчёт не обращается к серверу, хранилищу или сессии дневника.

## Проверка

Граница проверок согласована: публичная функция «карточки → строки рейтинга».
[Восемь тестов ядра](../../../../../tests/calculator-engine.test.mjs) запускаются
через `node --test tests/calculator-engine.test.mjs`, без UI, БД и сервера.
Проверяются независимые табличные эталоны обоих полов, десятичный ввод,
неполные карточки, ничьи `1, 1, 3` и `1, 2, 2, 4`, близкие итоги,
пересчёт изменённых карточек, неизменность входа, отсутствие итогов,
отрицательные коэффициенты и неконечные вычисления.

Проверка типов — `npm run typecheck`. Полная проверка чистого снимка по
[E006-T001](../../e006-delivery-foundation/checks.md) включает установку по lockfile,
форматирование, типы, сборку и полный набор тестов. Chromium берётся из общего
пользовательского кэша. Review выполняется относительно `e5a239d` отдельно
по соглашениям и требованиям.

Покрытие приёмки эпика: позиции 1–6 и 8 в части Уилкса. Общие проверки всех
формул и переключения формулы остаются в E007-T002–T004.

## Результат и продолжение

Реализованы разбор чисел, оригинальный Уилкс и полный рейтинг с идентификаторами,
порядком добавления, местами и лидерами. Проверенные коэффициенты и независимые
эталоны приведены в [справочнике Уилкса](../wilks-reference.md).
Контракт готов для последующей интеграции E008; интерфейс не изменён.
Полная проверка чистого дерева `78abc32d4a483de92f6856a67933190a964c7519`
завершилась успешно: установка по lockfile, Chromium из пользовательского кэша
без скачивания, синтетическая PostgreSQL, Prisma, форматирование, типы, сборка,
71/71 тест без пропусков и очистка ресурсов. Дальнейшие правки результата
проверки и реестра относятся только к документации.
Итоговый независимый review относительно `e5a239d` завершён: Standards —
0 замечаний, Spec — 0 замечаний. Относительные ссылки изменённых документов проверены.
IPF GL, DOTS и общая приёмка трёх формул остаются последующим задачам;
их реализация в T001 не выполняется.
