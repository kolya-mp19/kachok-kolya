# E007-T004. Сохранять корректный рейтинг на ничьих и краях диапазона

## Что сделать

**Что даёт:** общий рейтинг всех формул устойчив к близким итогам, неполным карточкам и необычным допустимым значениям.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — результаты S02 (завершённые E004–E006), подготовленные на основе согласованного S01. Расчётный контракт проверяется независимо от интерфейса и данных дневника; первоисточники формул проверяются при выполнении задач, а не считаются проверенными заранее.

**Заблокирована:** [E007-T002](t002-ipf-gl-comparison.md), [E007-T003](t003-dots-comparison.md).

## Критерии готовности

- [ ] Для каждого пола и формулы проверены малый/большой положительный собственный вес, конечный отрицательный коэффициент, резкий рост и неконечность без новых ограничений ввода.
- [ ] Примеры `40; 40; 39` и `40.004; 40.003` дают соответственно `1; 1; 3` с двумя лидерами и `1; 2` с одним; коэффициент перед умножением не округляется.
- [ ] Равные строки и строки без итога сохраняют порядок добавления; последние идут после ранжируемых без места, при отсутствии итогов нет лидеров.
- [ ] Выходной контракт и контрольные примеры переданы E008, короткие подписи не меняют места.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 2–8, итоговая сверка позиции 1. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
