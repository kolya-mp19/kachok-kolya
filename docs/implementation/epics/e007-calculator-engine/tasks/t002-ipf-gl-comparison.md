# E007-T002. Рассчитывать сравнение по IPF GL Classic Powerlifting

## Что сделать

**Что даёт:** та же сессия пересчитывается по выбранному продуктом набору IPF GL.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Локальная реализация разрешена по согласованному стеку; внешние интеграции и выпуск отложены. Общий вход — локальные результаты S02: E004, E005 и E006-T001. Внешние задачи E003 и E006-T002/T003 локальное исполнение не блокируют. Расчётный контракт проверяется независимо от интерфейса и данных дневника; первоисточники формул проверяются при выполнении задач, а не считаются проверенными заранее.

**Заблокирована:** [E007-T001](t001-wilks-comparison.md) — общий контракт вычислений и ранжирования.

## Критерии готовности

- [ ] По первичной публикации мая 2020 зафиксированы уравнения и коэффициенты Classic Powerlifting обоих полов и независимые эталоны; Bench Press/Equipped исключены.
- [ ] Переключение общей формулы пересчитывает итоги, места, равенства и лидеров; это справочная адаптация для бицепса.
- [ ] Неполный и неконечный расчёт сохраняет карточку без коэффициента, итога и места, не блокируя остальных.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 1, 3, 7–8 в части IPF GL. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
