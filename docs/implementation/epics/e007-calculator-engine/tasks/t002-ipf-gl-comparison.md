# E007-T002. Рассчитывать сравнение по IPF GL Classic Powerlifting

## Что сделать

**Что даёт:** та же сессия пересчитывается по выбранному продуктом набору IPF GL.

Согласованный стек и локальные входы S02 получены; расчёт — чистые функции
TypeScript по общему контракту [T001](./t001-wilks-comparison.md).
Внешние задачи E003 и E006-T002/T003 локальное исполнение не блокируют.
Внешние интеграции, деплой и выпуск отложены.

Локальных блокеров нет. Источник статуса — реестр задач в карточке эпика.

## Критерии готовности

- [x] По первичной публикации мая 2020 зафиксированы уравнения и коэффициенты Classic Powerlifting обоих полов и независимые эталоны; Bench Press/Equipped исключены.
- [x] Переключение общей формулы пересчитывает итоги, места, равенства и лидеров; это справочная адаптация для бицепса.
- [x] Неполный и неконечный расчёт сохраняет карточку без коэффициента, итога и места, не блокируя остальных.

## Проверка

Согласованная граница — публичная функция «карточки → строки рейтинга».
[Четыре теста IPF GL](../../../../../tests/calculator-ipf-gl.test.mjs) проверяют
независимые протоколы обоих полов, смену лидера и равенств при переключении формулы,
неизменность входа, неполные и неконечные строки, положительный вес ниже спортивных
порогов. Команда: `node --test tests/calculator-engine.test.mjs tests/calculator-ipf-gl.test.mjs`.
Все 12 вычислительных тестов и `npm run typecheck` пройдены.
Полная проверка чистого снимка выполняется по
[E006-T001](../../e006-delivery-foundation/checks.md), review — относительно `638043d`.
Покрытие приёмки эпика: позиции 1, 3, 7–8 в части IPF GL.

## Результат и продолжение

Реализованы IPF GL Classic Powerlifting обоих полов и выбор общей формулы `ipf-gl`.
Общий расчёт сохраняет отсутствие величин и места при неполном или неконечном
вычислении. Проверенные уравнение, коэффициенты, контрольные значения и допуски
приведены в [справке IPF GL](../ipf-gl-reference.md).
Полный прогон чистого дерева `2df830c4889c1e11cba4599ab5e578cd561ffcff`
успешен: установка по lockfile, Chromium из общего кэша без скачивания,
синтетическая PostgreSQL, Prisma, форматирование, типы, сборка, 75/75 тестов
без пропусков и очистка ресурсов. Итоговый независимый review относительно
`638043d`: Standards — 0 замечаний, Spec — 0 замечаний. Относительные ссылки
документации проверены. Последующие изменения результата и реестров — только документация.
Интерфейс E008 не изменён; DOTS и общая приёмка трёх формул выполнены отдельно
в [T003](./t003-dots-comparison.md) и [T004](./t004-ranking-boundaries.md).
