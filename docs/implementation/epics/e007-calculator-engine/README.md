# E007. Расчётное ядро калькулятора

Эпик шага **S03** из [общего плана](../../README.md).
Результат — проверяемые вычисления трёх формул и построение рейтинга.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- Реализовано ядро оригинального Уилкса; источники и контракт закреплены в PRD.
- [E007-T001](./tasks/t001-wilks-comparison.md) завершена: полный прогон чистого снимка — 71/71 тест без пропусков; review соглашений и требований — без замечаний.
- Активной задачи нет. Следующее действие по отдельному поручению — [E007-T002](./tasks/t002-ipf-gl-comparison.md); IPF GL, DOTS и итоговая приёмка трёх формул остаются впереди.
- Локальная реализация и необходимые зависимости разрешены по согласованному стеку; внешние интеграции и выпуск отложены.

## Зависимости

S02 (E004–E006) предоставляет среду запуска и проверок на основе согласованного S01 стека. Данные дневника
и вход не требуются. [E008](../e008-calculator-experience/README.md) использует ядро
для полного мобильного сценария; S11 получает результаты вычислительных проверок.
