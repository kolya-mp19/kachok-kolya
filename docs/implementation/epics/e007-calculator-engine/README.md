# E007. Расчётное ядро калькулятора

Эпик шага **S03** из [общего плана](../../README.md).
Результат — проверяемые вычисления трёх формул и построение рейтинга.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- Реализованы оригинальный Уилкс, IPF GL Classic Powerlifting и DOTS; источники и контракт закреплены в PRD.
- [E007-T001](./tasks/t001-wilks-comparison.md) завершена: полный прогон чистого снимка — 71/71 тест без пропусков; review соглашений и требований — без замечаний.
- [E007-T002](./tasks/t002-ipf-gl-comparison.md) завершена: чистый снимок — 75/75 тестов без пропусков; review соглашений и требований — без замечаний.
- [E007-T003](./tasks/t003-dots-comparison.md) завершена: чистый снимок — 79/79 тестов без пропусков; review соглашений и требований — без замечаний.
- [E007-T004](./tasks/t004-ranking-boundaries.md) завершена: общая матрица — 25/25 тестов, чистый снимок — 104/104 теста без пропусков; review соглашений и требований — без замечаний.
- Расчётное ядро принято, все четыре задачи выполнены. [Контракт и контрольные сценарии](./engine-handoff.md) переданы E008.
- Активной задачи нет. Следующее действие по отдельному поручению — [E008](../e008-calculator-experience/README.md), мобильный интерфейс калькулятора. S03 остаётся в работе до его реализации и приёмки.
- Локальная реализация и необходимые зависимости разрешены по согласованному стеку; внешние интеграции и выпуск отложены.

## Зависимости

S02 (E004–E006) предоставляет среду запуска и проверок на основе согласованного S01 стека. Данные дневника
и вход не требуются. [E008](../e008-calculator-experience/README.md) использует ядро
для полного мобильного сценария; S11 получает результаты вычислительных проверок.
