# E005. Основа хранения и сохранности ввода

Эпик шага **S02 «Подготовить работающую основу приложения»** из
[общего плана](../../README.md). Объём и приёмка — в [PRD](./prd.md).
Статус ведётся только в [реестре эпиков](../README.md).

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задачи ещё не созданы; активной задачи нет.
- Следующее действие: после согласования с пользователем решений S01 и подготовки
  [E004](../e004-project-foundation/README.md) разбить эпик на задачи.
- До согласования S01 проект не создаётся и зависимости не устанавливаются.

## Зависимости и результат

Вход — согласованные решения S01 о хранении, миграциях, владении данными и сохранении
ввода, а также структура и локальный запуск E004. Выход — подключение хранилища дневника,
механизм миграций и технические границы, которые используют S04–S10.
Тестовая эксплуатация основы проверяется в [E006](../e006-delivery-foundation/README.md).

Функциональная проверка владения проводится в S04, а сохранения реального ввода — в S07.
Реестр задач появится здесь отдельно; перед остановкой работы текущая точка дополняется
ссылкой на активную задачу и конкретным действием для продолжения.
