# E005-T003. Сохранять неподтверждённый ввод на технической границе

## Что сделать

**Что даёт:** будущие формы используют согласованный механизм, в котором ошибка отправки не стирает введённое.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — завершённые E001–E003, согласованный с владельцем стек и соответствующие решения в PRD.

**Заблокирована:** [E005-T002](t002-owned-operation.md); общие мобильные состояния [E004-T003](../../e004-project-foundation/tasks/t003-loading-and-errors.md).

## Критерии готовности

- [ ] Технический проход различает введённое, отправленное и подтверждённое; контролируемый неуспех сохраняет ввод.
- [ ] Поддержаны согласованные S01 правила повторной отправки, без оффлайн-синхронизации и хранения сессии калькулятора.
- [ ] Инструкция объясняет подключение границы; реальный ввод плана и факта остаётся приёмкой S06–S07.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 1, 7–9; итоговая сверка 2–6. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
