# E010-T003. Подтверждать отсутствующую почту до создания дневника

## Что сделать

**Что даёт:** атлет продолжает вход любого провайдера без предоставленной почты через ввод адреса и действие из письма.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — результаты S02 (завершённые E004–E006), подготовленные на основе согласованного S01. Нужен готовый E009 и согласованный проект доступа. До подключения проверяются актуальные официальные инструкции и доступность интеграций для выбранного приложения. Каждый срез включает защищённые операции, хранение, русские мобильные формы и проверку результата.

**Заблокирована:** [E010-T001](t001-yandex-login.md), [E010-T002](t002-vk-login.md); подтверждение почты E009.

## Критерии готовности

- [ ] До подтверждения новой почты дневник не создаётся; повтор завершения не создаёт дубликат.
- [ ] Существующий адрес не даёт доступ и не создаёт второй дневник: показан вход прежним способом или восстановление с последующим явным подключением.
- [ ] Отмена, неуспешное подтверждение и сбой доставки оставляют существующие данные без изменений; поток доступен с телефона.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A3, A4 в части запрета доступа по совпадению, A7.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
