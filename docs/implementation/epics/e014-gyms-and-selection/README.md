# E014. Залы и выбор упражнений при планировании

Эпик шага S05 [общего плана](../../README.md). Поведение и приёмка — в
[PRD](./prd.md); актуальный статус — в [реестре эпиков](../README.md).

## Текущая точка

- PRD подготовлен; реализация не начата.
- Количество задач: 3; разбивка согласована, файлы созданы; активной задачи нет.
- Следующее действие: после получения входов из зависимостей уточнить проверки по решениям S01
  и начать [E014-T001](./tasks/t001-first-gym-selection.md).
- Подготовка задач не согласует стек: до реализации результаты S01 переносятся в PRD,
  конкретные проверки уточняются по выбранным технологиям.

## Зависимости

- [E012](../e012-exercise-catalog/README.md): поиск, создание и свойства упражнения.
- S01: согласованные с владельцем техническая основа и мобильные сценарии.
- S06 подключает выбор и зал к реальному редактору плана; S10 показывает зал на графиках.
  Они не являются обратными зависимостями завершения S05.
