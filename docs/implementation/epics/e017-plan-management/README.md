# E017. Копирование и границы правки плана

Эпик шага **S06** из [общего плана](../../README.md).
Результат — повторное использование структуры и сохранение исходного намерения после фиксации.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задач нет; их реестр и каталог появятся при детализации уровня 3.
- Следующее действие: после E015/E016 подготовить задачи и согласовать контракт фиксации с E019.

## Зависимости

[E015](../e015-cycle-lifecycle/README.md) задаёт календарные границы,
[E016](../e016-plan-entry/README.md) — структуру плана.
E019/E020 подключают первый факт, позднюю замену и исправления;
E022 — подсказки к скопированной структуре. Их будущая интеграция не блокирует
копирование без весов и защиту плана по календарю.
