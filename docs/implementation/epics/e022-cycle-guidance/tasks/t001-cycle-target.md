# E022-T001. Согласовать прибавку и сохранить цель нового цикла

## Что сделать

При следующем развивающем цикле атлет выбирает тип прибавки без умолчания и подтверждает объяснимую цель.

Срез включает сохранение, операции владельца, мобильное представление и проверку своего поведения. Для изменяемых потоков проверяются доступ двух атлетов, повторная отправка и сохранность ввода.

Перед выполнением согласованные решения [S01](../../../README.md) должны быть перенесены в PRD; технологии и конкретные проверки уточняются по этим решениям. Подготовка задач не означает согласования технологического стека или начала реализации.

Источник: [PRD E022](../prd.md).

**Заблокирована:** [E021-T002](../../e021-max-history/tasks/t002-max-growth-and-failure.md); [E015](../../e015-cycle-lifecycle/prd.md) — создание цикла; [E012](../../e012-exercise-catalog/prd.md) — тип, шаг и единицы упражнения.

## Критерии готовности

- [ ] Положительная величина обязательна для процентов/килограммов
- [ ] Опоры сохраняются для всех основных упражнений с МПВ, включая пока не включённые в план
- [ ] Обычная смена действует только со следующего цикла
- [ ] Показаны расчёт и действительная прибавка
- [ ] Проверены цели 100+1/3/3.75, равные расстояния и ручная некратная цель
- [ ] «без прибавки» не округляет опору вверх
- [ ] Цель у положения в цикле не объявляется достижением, чужая операция отклоняется.
- [ ] Текущие тип и величина прибавки с историей доступны контракту окна связи; его подключение и выбор конфликтующих настроек выполняет [E023-T001](../../e023-progression-and-return/tasks/t001-weight-selection.md) без изменения сохранённых опор, целей и планов. Готовность этого позднего окна не блокирует E022-T001.

## Проверка

Пройти описанный сценарий по критериям готовности и сверить наблюдаемый результат с [PRD эпика](../prd.md). Проверить допустимые и недопустимые входы, границы исправлений и сохранность исходных записей там, где они затронуты.

Покрытие приёмки эпика: A1–A4, A8.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре [карточки эпика](../README.md). При выполнении зафиксировать проверенный результат; перед остановкой обновить там текущую точку и конкретное следующее действие.
