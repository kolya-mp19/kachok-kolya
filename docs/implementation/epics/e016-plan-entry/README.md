# E016. Структурированный план и быстрый ввод

Эпик шага **S06** из [общего плана](../../README.md).
Результат — ручное составление плана с телефона нотацией или пошаговым вводом.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задач нет; их реестр и каталог появятся при детализации уровня 3.
- Следующее действие: после E015 подготовить задачи; до реализации уточнить критерии
  сравнения с прошлым выполнением по [PLAN-Q1](../../../requirements/week-planning/open-questions.md).

## Зависимости

[E015](../e015-cycle-lifecycle/README.md) предоставляет активный цикл и недели;
S05 — выбор упражнения, единицу веса, шаг оборудования и зал.
[E017](../e017-plan-management/README.md) добавляет копирование и ограничения правки.
История подключается в E020, предписание — в E022; их отсутствие не запрещает ручной ввод.
