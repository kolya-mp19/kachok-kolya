# E016-T004. Согласовать критерии подозрительного отклонения от истории

## Что сделать

Закрытый [PLAN-Q1](../../../../requirements/week-planning/open-questions.md) позволяет однозначно реализовать сравнение числа подходов, повторений и веса.

Результат — документация и согласованное продуктовое правило. Код приложения,
стартовый проект, зависимости и инфраструктура в эту задачу не входят.

**Заблокирована:** нет — обсуждение можно начинать сразу.

## Критерии готовности

- [ ] Владелец подтвердил критерии и примеры срабатывания/несрабатывания.
- [ ] Решение записано в бизнес-спеку по правилам документации, маркер и вопрос сняты.
- [ ] Произвольные пороги не объявлены принятыми до согласования.

## Проверка

Сверить согласованные критерии с владельцем продукта на примерах срабатывания
и несрабатывания; проверить перенос решения в бизнес-спеку и PRD.

Покрытие приёмки эпика: пункт 6 (решение вопроса); это задача документации. Пункты отсчитываются по порядку чекбоксов основного раздела приёмки PRD; это не идентификаторы A#.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре карточки
эпика. При выполнении уточнить PRD по согласованным решениям; перед остановкой
обновить там текущую точку и следующее действие.
