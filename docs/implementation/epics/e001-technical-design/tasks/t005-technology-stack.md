# E001-T005. Согласовать технологический стек

## Что сделать

Представить владельцу продукта конкретный технический вариант, сравнить его с альтернативами и получить согласование основы будущего приложения.

Результат — документация и согласованные проектные решения. Код приложения, стартовый
проект, зависимости и инфраструктура в задачу не входят.

**Заблокирована:** [E001-T001 — Согласовать ограничения технической основы](./t001-constraints.md); [E001-T004 — Спроектировать исправления и пересчёт истории](./t004-history-recalculation.md)

## Критерии готовности

- [x] Сравнение учитывает сопровождение одним владельцем, воспроизводимость запуска, мобильный ввод, вход через провайдеров, стоимость и восстановление данных.
- [x] Проверена пригодность вариантов для модели, календарных переходов, фиксации и пересчётов из предыдущих задач.
- [x] Выбраны технологии интерфейса, сервера, хранения и миграций; границы ответственности технологий и размещения согласованы с E003.
- [x] Конкретные варианты и сведения о внешних сервисах проверены по актуальным первичным источникам при выполнении задачи.
- [x] Владелец продукта явно согласовал стек; решение, причины и реальные альтернативы записаны в ADR, остальные подробности — в PRD.
- [x] Проект, зависимости и конфигурация сборки не создаются в рамках задачи.

## Проверка

Провести обзор сравнения с владельцем; сверить выбранный вариант со всеми обязательными ограничениями и сценариями T002–T004.

Покрытие приёмки эпика: A1, A8.
