# E001-T008. Проверить целостность проекта и передать решения дальше

## Что сделать

Подтвердить завершённость технического проекта и передать конкретные согласованные решения в последующие PRD, чтобы S02 начинался без повторного выбора основы.

Результат — документация и согласованные проектные решения. Код приложения, стартовый
проект, зависимости и инфраструктура в задачу не входят.

**Заблокирована:** [E001-T004 — Спроектировать исправления и пересчёт истории](./t004-history-recalculation.md); [E001-T007 — Спроектировать сохранность ввода и повтор отправки](./t007-input-preservation.md)

## Критерии готовности

- [ ] Каждый критерий A1–A8 PRD E001 сопоставлен с принятым решением и проверочным примером; все обязательные сценарии пройдены.
- [ ] Устранены противоречия между моделью, стеком, календарём, пересчётами, доступом и протоколом ввода.
- [ ] Совместимость с мобильными потоками E002 и эксплуатацией E003 подтверждена по конкретным результатам, а не только наличию их PRD.
- [ ] Решения перенесены в PRD S02 и остальных зависимых эпиков; технические варианты не оставлены вместо принятых решений.
- [ ] ADR оформлены по критериям реестра, ссылки корректны, новые продуктовые правила и отложенные функции не добавлены.
- [ ] Оставшиеся действия и прогресс отражены по правилам документации; завершение E001 не объявляет завершёнными E002, E003 или весь S01.

## Проверка

Провести сквозной обзор всех сценариев PRD, матрицы A1–A8 и зависимых PRD; проверить относительные ссылки и согласованность терминов.

Покрытие приёмки эпика: A1–A8.

## Результат и продолжение

Проектный результат ещё не подготовлен. При выполнении записать решения в PRD и,
если применимы критерии реестра, в ADR. Состояние задачи ведётся только в реестре
карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
