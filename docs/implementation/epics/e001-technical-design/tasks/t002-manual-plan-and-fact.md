# E001-T002. Спроектировать первый ручной план и факт

## Что сделать

Описать законченный путь атлета от пустого дневника до первого подхода без МПВ, проверив на нём границы модулей, операции и логическую модель.

Результат — документация и согласованные проектные решения. Код приложения, стартовый
проект, зависимости и инфраструктура в задачу не входят.

**Заблокирована:** Нет — можно начинать сразу.

## Критерии готовности

- [ ] Схема модулей и публичных операций показывает независимость калькулятора: только память вкладки, без сервера, аккаунта и данных дневника.
- [ ] Модель определяет владение и идентификаторы, различает незавершённый ввод, редактируемый и зафиксированный план, факт, исторические условия и производные результаты.
- [ ] Показаны структурное представление нотации, роли подходов, копия без весов и заполнение обязательных значений до первой отметки.
- [ ] Первый подход фиксирует план всей тренировки; разминка имеет отдельный момент фиксации, её отметка не фиксирует основную часть.
- [ ] Тип упражнения относится к зафиксированному плану, подбор веса — к конкретному выполнению; предписание цикла вычисляется и не хранится как самостоятельный план.

## Проверка

Пройти пример первого цикла без МПВ от ввода плана до записи факта; для каждого действия указать вход, изменение состояния и доступный пользователю результат.

Покрытие приёмки эпика: A2, A3.

## Результат и продолжение

Проектный результат ещё не подготовлен. При выполнении записать решения в PRD и,
если применимы критерии реестра, в ADR. Состояние задачи ведётся только в реестре
карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
