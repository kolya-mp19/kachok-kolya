# E001-T001. Согласовать ограничения технической основы

## Что сделать

Согласовать с владельцем продукта ограничения, по которым можно сравнивать технические варианты без предположений о бюджете, навыках и эксплуатации.

Результат — документация и согласованные проектные решения. Код приложения, стартовый
проект, зависимости и инфраструктура в задачу не входят.

**Заблокирована:** Нет — можно начинать сразу.

## Критерии готовности

- [ ] Уточнены навыки владельца, доступное окружение разработки и возможности сопровождения.
- [ ] Из E002 получены необходимые ограничения мобильного ввода, из E003 — бюджета, внешних доступов и восстановления; значения подтверждены владельцем.
- [ ] Разделены обязательные ограничения и предпочтения; нерешённые технические вопросы имеют конкретное следующее действие.
- [ ] Получение входных ограничений не требует завершения E002 и E003 целиком и не создаёт круговой зависимости.

## Проверка

Сверить ограничения с владельцем и ответственностью E002/E003; показать, как каждое ограничение будет использоваться при сравнении стека.

Покрытие приёмки эпика: A1, A8.

## Результат и продолжение

Проектный результат ещё не подготовлен. При выполнении записать решения в PRD и,
если применимы критерии реестра, в ADR. Состояние задачи ведётся только в реестре
карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
