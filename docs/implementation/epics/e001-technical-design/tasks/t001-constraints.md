# E001-T001. Согласовать ограничения технической основы

## Что сделать

Согласовать с владельцем продукта ограничения, по которым можно сравнивать технические варианты без предположений о бюджете, навыках и эксплуатации.

Результат — документация и согласованные проектные решения. Код приложения, стартовый
проект, зависимости и инфраструктура в задачу не входят.

**Заблокирована:** Нет — можно начинать сразу.

## Критерии готовности

- [x] Уточнены навыки владельца, доступное окружение разработки и возможности сопровождения.
- [x] Из E002 получены необходимые ограничения мобильного ввода, из E003 — бюджета, внешних доступов и восстановления; значения подтверждены владельцем либо явно исключены им из текущего объёма.
- [x] Разделены обязательные ограничения и предпочтения; нерешённые технические вопросы имеют конкретное следующее действие.
- [x] Получение входных ограничений не требует завершения E002 и E003 целиком и не создаёт круговой зависимости.

## Проверка

Сверить ограничения с владельцем и ответственностью E002/E003; показать, как каждое ограничение будет использоваться при сравнении стека.

Покрытие приёмки эпика: A1, A8.

## Результат и продолжение

Результат: [ограничения технической основы](../design/constraints.md).
Подтверждены TypeScript, один сервер с Docker Compose и сопровождение по инструкции.
Копии исключены из объёма E001; проект восстановления относится к E003.
Бюджет исключён из рассмотрения, внешние доступы проверяются в E003.
Продолжение — проверка стека в T005. Состояние ведётся в карточке эпика.
