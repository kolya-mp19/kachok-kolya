# E025-T002. Явно начать следующий цикл из итогов

## Что сделать

Атлет выбирает следующий цикл, при необходимости проходит пересмотр и выбор прибавки, явно переносит только допустимую структуру.

Срез включает сохранение, операции владельца, мобильное представление и проверку своего поведения. Для изменяемых потоков проверяются доступ двух атлетов, повторная отправка и сохранность ввода.

Перед выполнением согласованные решения [S01](../../../README.md) должны быть перенесены в PRD; технологии и конкретные проверки уточняются по этим решениям. Подготовка задач не означает согласования технологического стека или начала реализации.

Источник: [PRD E025](../prd.md).

**Заблокирована:** [E025-T001](t001-cycle-results.md), [E023-T005](../../e023-progression-and-return/tasks/t005-return-and-revision.md), [E022-T001](../../e022-cycle-guidance/tasks/t001-cycle-target.md); [E017](../../e017-plan-management/prd.md) — допустимый перенос структуры.

## Критерии готовности

- [ ] Без активного цикла доступны история и исправления, новая тренировка вне цикла закрыта
- [ ] Нет автоматического следующего
- [ ] Провал сам не пересматривает МПВ
- [ ] Допустимая структура переносит выбранные разминочные комплексы по [E017](../../e017-plan-management/prd.md) и правилам подстановки [E018](../../e018-warmup/prd.md), но не копирует веса, факт, RPE, отметки и фактические результаты разминки; смена шаблона не допускает пакетного переноса.
- [ ] Календарные ограничения и фиксация сохранены.

## Проверка

Пройти описанный сценарий по критериям готовности и сверить наблюдаемый результат с [PRD эпика](../prd.md). Проверить допустимые и недопустимые входы, границы исправлений и сохранность исходных записей там, где они затронуты.

Для допустимого переноса взять тренировку с выбранным разминочным комплексом,
отметкой выполнения или пропуска и введёнными результатами. В новой структуре
сохранён выбор комплекса, но нет прежней отметки, причины пропуска и фактических
результатов; исходная историческая разминка не изменена.

Покрытие приёмки эпика: пункты 6, 7.

В этом PRD «пункт N» означает позицию чекбокса в разделе приёмки, считая сверху с единицы; новая нумерация в PRD не вводится.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре [карточки эпика](../README.md). При выполнении зафиксировать проверенный результат; перед остановкой обновить там текущую точку и конкретное следующее действие.
