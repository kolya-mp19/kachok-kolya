# E004. Структура проекта и мобильная оболочка

Эпик шага **S02 «Подготовить работающую основу приложения»** из
[общего плана](../../README.md). Объём и приёмка — в [PRD](./prd.md).
Статус ведётся только в [реестре эпиков](../README.md).

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задачи ещё не созданы; активной задачи нет.
- Следующее действие: после согласования с пользователем решений S01 разбить эпик
  на задачи с конкретными командами и критериями проверки выбранных технологий.
- До этого согласования проект не создаётся и зависимости не устанавливаются.

## Зависимости и результат

Вход — завершённые **E001–E003** шага S01 и согласованные с пользователем решения о технологиях, границах контекстов
и мобильном интерфейсе. Выход — воспроизводимый локальный запуск и мобильная оболочка
с раздельными границами калькулятора и дневника. Она используется
[E005](../e005-storage-foundation/README.md) и [E006](../e006-delivery-foundation/README.md),
а также функциональными эпиками S03–S04.

Реестр задач появится здесь при отдельной детализации. Перед остановкой работы текущая
точка дополняется ссылкой на задачу и конкретным действием для продолжения.
Наличие PRD не означает завершения эпика: нужны результаты приёмки реализации.
