## Зависимости и результат

Вход — завершённые **E001–E003** шага S01 и согласованные с пользователем решения о технологиях, границах контекстов
и мобильном интерфейсе. Выход — воспроизводимый локальный запуск и мобильная оболочка
с раздельными границами калькулятора и дневника. Она используется
[E005](../e005-storage-foundation/README.md) и [E006](../e006-delivery-foundation/README.md),
а также функциональными эпиками S03–S04.

Перед остановкой работы текущая точка дополняется ссылкой на задачу и конкретным действием для продолжения.
Наличие PRD не означает завершения эпика: нужны результаты приёмки реализации.
