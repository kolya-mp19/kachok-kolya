# E004. Структура проекта и мобильная оболочка

Эпик шага **S02 «Подготовить работающую основу приложения»** из
[общего плана](../../README.md). Объём и приёмка — в [PRD](./prd.md).
Статус ведётся только в [реестре эпиков](../README.md).

## Текущая точка

- Локальная основа [E004-T001](./tasks/t001-local-launch.md) реализована по согласованному стеку.
- Разрешена реализация всего приложения локально без внешних интеграций и выпуска; E003/S01 остаются незавершёнными и локальную работу не блокируют.
- Мобильная навигация [E004-T002](./tasks/t002-mobile-navigation.md) реализована; прямые ссылки и компоновка проверены в Chrome при ширинах 320/360/390 CSS-пикселей. Проверка реальных мобильных браузеров не заявляется.
- Состояния [E004-T003](./tasks/t003-loading-and-errors.md) реализованы: ожидание модуля, безопасное сообщение об ошибке, обновление и доступная навигация. Браузерная проверка обеих точек входа пройдена в Chromium; реальные мобильные устройства не проверены.
- Итоговая проверка чистой копии пройдена: установка по lockfile, сборка с проверкой типов и все 7 тестов. Независимые ревью стандартов и требований завершены; замечание очистки тестового процесса исправлено. Прямые ссылки проверены также при скрытом каталоге в пути checkout.
- Активной задачи нет. Локальный [E005](../e005-storage-foundation/README.md) принят. Следующее действие — начать локальные автопроверки [E006-T001](../e006-delivery-foundation/tasks/t001-automated-checks.md), затем функциональные эпики. E003 и внешние задачи E006-T002/T003 локальную работу не блокируют. Реальные Safari iOS и Chrome Android остаются в матрице фактической приёмки.
- Задачи выполняются последовательно T001 → T002 → T003; независимая подготовка и проверка документов допускаются параллельно.

## Зависимости и результат

Вход локального E004 — завершённые **E001–E002** и согласованные с пользователем решения о технологиях, границах контекстов
и мобильном интерфейсе. Локальная реализация всего приложения разрешена до завершения E003; внешние интеграции и выпуск отложены. Выход — воспроизводимый локальный запуск и мобильная оболочка
с раздельными границами калькулятора и дневника. Она используется
[E005](../e005-storage-foundation/README.md) и [E006](../e006-delivery-foundation/README.md),
а также функциональными эпиками S03–S04.

Перед остановкой работы текущая точка дополняется ссылкой на задачу и конкретным действием для продолжения.
Наличие PRD не означает завершения эпика: нужны результаты приёмки реализации.
