# E004-T001. Запускать пустую оболочку из чистого рабочего каталога

## Что сделать

**Что даёт:** разработчик по инструкции получает работающую оболочку на согласованной основе.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — завершённые E001–E003, согласованный с владельцем стек и соответствующие решения в PRD.

**Заблокирована:** завершённые E001–E003 и согласованные решения в PRD.

## Критерии готовности

- [ ] PRD содержит ссылки на согласованные решения; структура и зависимости им соответствуют.
- [ ] Предварительные условия, установка, конфигурация и локальный запуск воспроизводятся в чистом каталоге без ручной правки исходников.
- [ ] Безопасный образец объясняет обязательные параметры; секретов нет в отслеживаемом коде и клиентской сборке.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 1–3. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
