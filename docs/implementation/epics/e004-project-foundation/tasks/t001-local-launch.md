# E004-T001. Запускать пустую оболочку из чистого рабочего каталога

## Что сделать

**Что даёт:** разработчик по инструкции получает работающую оболочку на согласованной основе.

Применяются согласованные решения E001/E002 и локальное исключение [PRD](../prd.md), раздел 3: владелец разрешил E004 до завершения E003 без внешних интеграций и выпуска. E003/S01 остаются незавершёнными.

**Вход:** завершённые E001/E002 и согласованные решения в PRD; локальное исключение до завершения E003.

## Критерии готовности

- [x] PRD содержит ссылки на согласованные решения; структура и зависимости им соответствуют.
- [x] Предварительные условия, установка, конфигурация и локальный запуск воспроизводятся в чистом каталоге без ручной правки исходников.
- [x] Безопасный образец объясняет обязательные параметры; секретов нет в отслеживаемом коде и клиентской сборке.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 1–3. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Результат — [инструкция локального запуска](../../../../../README.md), React/Vite в
[клиенте](../../../../../apps/web/src/main.tsx), NestJS в [сервере](../../../../../apps/api/src/main.ts),
фиксированные зависимости и lockfile. Образец конфигурации не содержит обязательных
секретов; оба процесса слушают loopback. API не использует БД и внешние сервисы.
Проверки: установка зависимостей, проверка типов клиента/сервера/конфигурации,
сборка и [HTTP-проверка](../../../../../tests/local-launch.test.mjs) запуска без внешних
сервисов, отдачи статики и JSON 404 неизвестного API. Навигация — T002, состояния — T003;
приёмка реальных мобильных браузеров не заявляется. Итоговая проверка чистой копии
и независимое ревью пройдены после всех задач E004. HTTP-проверка включает скрытый
каталог checkout и прямые ссылки обеих точек входа. Состояние и продолжение —
в [карточке эпика](../README.md).
