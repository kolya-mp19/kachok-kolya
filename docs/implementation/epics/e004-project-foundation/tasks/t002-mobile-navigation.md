# E004-T002. Открывать независимые контексты через мобильную навигацию

## Что сделать

**Что даёт:** пользователь открывает, обновляет и явно выбирает точки входа калькулятора и дневника.

Применяются согласованные решения E001/E002 и локальное исключение [PRD](../prd.md), раздел 3: владелец разрешил E004 до завершения E003 без внешних интеграций и выпуска. E003/S01 остаются незавершёнными.

**Заблокирована:** [E004-T001](t001-local-launch.md).

## Критерии готовности

- [ ] Прямое открытие и обновление обеих точек входа работают; оболочка и навигация доступны на согласованном мобильном размере без горизонтальной прокрутки.
- [ ] Граница калькулятора и общая оболочка не требуют аутентификации, хранилища или доменных данных дневника.
- [ ] Временные состояния честно обозначают ещё отсутствующие сценарии, без фиктивного успешного выполнения.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 4–7. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
