# E004-T002. Открывать независимые контексты через мобильную навигацию

## Что сделать

**Что даёт:** пользователь открывает, обновляет и явно выбирает точки входа калькулятора и дневника.

Применяются согласованные решения E001/E002 и локальное исключение [PRD](../prd.md), раздел 3: владелец разрешил E004 до завершения E003 без внешних интеграций и выпуска. E003/S01 остаются незавершёнными.

**Заблокирована:** [E004-T001](t001-local-launch.md).

## Критерии готовности

- [x] Прямое открытие и обновление обеих точек входа работают; оболочка и навигация доступны на согласованном мобильном размере без горизонтальной прокрутки.
- [x] Граница калькулятора и общая оболочка не требуют аутентификации, хранилища или доменных данных дневника.
- [x] Временные состояния честно обозначают ещё отсутствующие сценарии, без фиктивного успешного выполнения.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 4–7. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

В [оболочке](../../../../../apps/web/src/App.tsx) доступны обычные ссылки
на `/calculator` и `/diary`; `/` открывает калькулятор. Активный раздел отмечен
текстовым оформлением и `aria-current`, переход к содержимому доступен с клавиатуры.
[Калькулятор](../../../../../apps/web/src/calculator/CalculatorPage.tsx) и
[дневник](../../../../../apps/web/src/diary/DiaryPage.tsx) загружаются отдельными
модулями по выбранному адресу. Калькулятор не загружает модуль дневника и не обращается
к API, сессии или хранилищу. Вместо будущих функций показаны честные пояснения.

Проверки типов и сборка прошли. На собранном приложении в установленном Chrome
проверены прямой вход, переход и перезагрузка обоих адресов, размеры 320/360/390
CSS-пикселей при высоте 280, увеличение текста до 200%, отсутствие горизонтальной
прокрутки, цели ссылок не менее 44 пикселей и клавиатурный переход к содержимому.
Сетевой журнал калькулятора не содержит запросов API и модуля дневника.
Этот прогон не заменяет проверку Safari iOS и Chrome Android на устройствах.
Далее — общие загрузка и ошибка в [T003](./t003-loading-and-errors.md),
повторяемые браузерные проверки и итоговое независимое ревью.
Состояние и продолжение — в [карточке эпика](../README.md).
