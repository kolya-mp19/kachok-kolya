# E004-T003. Понятно показывать загрузку и общую ошибку оболочки

## Что сделать

**Что даёт:** при ожидании или сбое обеих точек входа пользователь сохраняет понятный контекст действия.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — завершённые E001–E003, согласованный с владельцем стек и соответствующие решения в PRD.

**Заблокирована:** [E004-T002](t002-mobile-navigation.md).

## Критерии готовности

- [ ] Общие состояния соответствуют E002, сообщения русские, служебные сведения пользователю не раскрываются.
- [ ] На мобильном экране показаны загрузка и контролируемый сбой; отдельный десктопный сценарий не добавлен.
- [ ] Инструкция запуска и проверка прямых ссылок остаются воспроизводимыми после добавления состояний.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 4, 7–8; итоговая сверка 1–6. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
