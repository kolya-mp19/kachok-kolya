# E004-T003. Понятно показывать загрузку и общую ошибку оболочки

## Что сделать

**Что даёт:** при ожидании или сбое обеих точек входа пользователь сохраняет понятный контекст действия.

Применяются согласованные решения E001/E002 и локальная область [PRD](../prd.md), раздел 3: разрешена реализация всего приложения локально до завершения E003 без внешних интеграций и выпуска. E003/S01 остаются незавершёнными.

**Заблокирована:** [E004-T002](t002-mobile-navigation.md).

## Критерии готовности

- [x] Общие состояния соответствуют E002, сообщения русские, служебные сведения пользователю не раскрываются.
- [x] На мобильном экране показаны загрузка и контролируемый сбой; отдельный десктопный сценарий не добавлен.
- [x] Инструкция запуска и проверка прямых ссылок остаются воспроизводимыми после добавления состояний.

## Проверка

После `npm run build` выполнить `node --test tests/mobile-shell.test.mjs` с установленным Chromium Playwright по [инструкции запуска](../../../../../README.md). Проверка задерживает настоящий запрос модуля каждой точки входа, наблюдает загрузку, затем разрешает ответ. Прерывание запроса проверяет общее сообщение, переход в другой раздел и восстановление кнопкой обновления; служебных маршрутов для проверки в приложении нет.

Покрытие приёмки эпика: позиции 4, 7–8; итоговая сверка 1–6. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

В обеих точках входа `Suspense` показывает «Загружаем раздел…», граница ошибки оставляет навигацию и предлагает обновление. Текст исключения не выводится. Состояния доступны через роли `status`/`alert`, действие восстановления имеет цель касания не менее 44 CSS-пикселей.

Сборка с проверкой типов и браузерный файл пройдены: 6 проверок, ширины 320/360/390, видимая высота 280, увеличение текста 200%, прямые входы, обновление и переходы. Калькулятор не запрашивает API/сессию и модуль дневника. Это проверка в Chromium на машине разработчика; реальные Safari iOS и Chrome Android остаются отдельной приёмкой по матрице E003.

Итоговый полный прогон из чистой копии и независимое ревью локального E004 пройдены; результаты и дальнейшие действия — в [карточке эпика](../README.md). Статус задачи ведётся только в её реестре; E003 и внешние доступы не объявляются завершёнными.
