# E023-T001. Управлять подбором веса с сохранением условий выполнения

## Что сделать

Новое упражнение автоматически находится в подборе, атлет может изменить состояние только этого упражнения без переписывания прошлого. При установке или переустановке связи он явно выбирает расходящиеся текущие тип прибавки и состояние подбора в существующем окне связи.

Срез включает сохранение, операции владельца, мобильное представление и проверку своего поведения. Для изменяемых потоков проверяются доступ двух атлетов, повторная отправка и сохранность ввода.

Перед выполнением согласованные решения [S01](../../../README.md) должны быть перенесены в PRD; технологии и конкретные проверки уточняются по этим решениям. Подготовка задач не означает согласования технологического стека или начала реализации.

Источник: [PRD E023](../prd.md).

**Заблокирована:** [E012](../../e012-exercise-catalog/prd.md) — появление упражнения; [E019](../../e019-workout-recording/prd.md) — первый факт; [E022-T002](../../e022-cycle-guidance/tasks/t002-apply-week-guidance.md) — тип прибавки и показ предписания; [E021-T002](../../e021-max-history/tasks/t002-max-growth-and-failure.md) — допустимость МПВ; [E013-T003](../../e013-exercise-linking/tasks/t003-confirm-current-preview.md) — предпросмотр и согласованное подтверждение связи.

## Критерии готовности

- [ ] Зал и перерыв сами подбор не включают
- [ ] Первый факт сохраняет состояние, поздний факт использует состояние на фактическую дату и тип плана
- [ ] Переключение посреди тренировки не меняет начатое выполнение
- [ ] Подбор убирает подсветку и исключает динамику, но не точность
- [ ] Первый МПВ допустим, повышение существующего закрыто
- [ ] Чужое состояние недоступно.
- [ ] В окне установки связи E013 подключены текущие тип и величина прибавки из E022 и состояние подбора. Совпадающие значения не требуют выбора; расходящиеся показаны явно и не объединяются молча.
- [ ] При переустановке текущие общие настройки предложены обеим получающимся историям; атлет явно выбирает или правит их для каждой стороны. Скрытого возврата к прежним настройкам нет.
- [ ] Подтверждение согласованно применяет только просмотренные связь и текущие настройки. Отмена ничего не меняет; повтор не дублирует применение; изменившиеся после предпросмотра входы требуют повторной проверки и подтверждения.
- [ ] Выбор текущих настроек не переписывает исторические тип и подбор выполнений, сохранённые опоры, цели и планы циклов. Изменение опоры принимается отдельно по E022.

Расчёт и предпросмотр МПВ/пересмотров остаются в [E021-T004](../../e021-max-history/tasks/t004-linked-max-preview.md), перезапуск серий при изменении связи — в [E023-T002](./t002-stable-selection-series.md). Эта задача подключает текущие настройки к уже существующей операции E013; новый механизм связи не создаётся.

## Проверка

Пройти описанный сценарий по критериям готовности и сверить наблюдаемый результат с [PRD эпика](../prd.md). Проверить допустимые и недопустимые входы, границы исправлений и сохранность исходных записей там, где они затронуты.

Для связи проверить личное упражнение с процентной прибавкой и включённым подбором
и системное с прибавкой в килограммах и выключенным подбором; затем — совпадающие
настройки и переустановку на другое системное. Проверить результаты обеих историй,
отмену, повтор и изменение настроек между предпросмотром и подтверждением.

Покрытие приёмки эпика: A1, A4, A9; поздняя интеграция [PRD E013](../../e013-exercise-linking/prd.md), пункты приёмки 2, 6, 8 в части текущих типа прибавки и подбора.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре [карточки эпика](../README.md). При выполнении зафиксировать проверенный результат; перед остановкой обновить там текущую точку и конкретное следующее действие.
