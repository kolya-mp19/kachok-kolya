# E027. Собственный вес и его история

Эпик шага **S10** из [общего плана](../../README.md).
Результат — отдельный экран собственного веса, ручные записи с датой и их график.

- [PRD](./prd.md) — границы, данные и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Разбиение согласовано; создано задач: 3. Активной задачи нет.
- Следующее действие: получить необходимые результаты зависимостей и согласованные решения S01, сверить их с PRD и перейти к [E027-T001](./tasks/t001-bodyweight-history.md).
- Согласованные решения S01 и конкретные проверки выбранных технологий уточняются до реализации; подготовка задач не заменяет эти входы.
- До реализации совпадающих дат собственного веса требуется решение [PROGRESS-Q1](../../../requirements/progress-analytics/open-questions.md).

## Зависимости

Завершённый S09: [E024](../e024-cycle-metrics/README.md) и
[E025](../e025-cycle-results/README.md). E025 предоставляет минимальное хранение веса,
однократный вопрос в итогах и ответ/пропуск. Здесь не создаётся второй вопрос или хранилище.
Стек следует согласованным с владельцем решениям S01.
