# E027. Собственный вес и его история

Эпик шага **S10** из [общего плана](../../README.md).
Результат — отдельный экран собственного веса, ручные записи с датой и их график.

- [PRD](./prd.md) — границы, данные и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задач нет; их реестр и каталог появятся при детализации уровня 3.
- Следующее действие: после S09 сверить контракт E025 и подготовить задачи;
  до реализации повторной записи на одну дату закрыть
  [PROGRESS-Q1](../../../requirements/progress-analytics/open-questions.md).
