# E027-T002. Записать собственный вес вручную на выбранную дату

## Что сделать

Независимо от активного цикла атлет по своей инициативе записывает вес с любой датой в тот же ряд.

Срез включает сохранение, операции владельца, мобильное представление и проверку своего поведения. Для изменяемых потоков проверяются доступ двух атлетов, повторная отправка и сохранность ввода.

Перед выполнением согласованные решения [S01](../../../README.md) должны быть перенесены в PRD; технологии и конкретные проверки уточняются по этим решениям. Подготовка задач не означает согласования технологического стека или начала реализации.

Источник: [PRD E027](../prd.md).

**Заблокирована:** [E027-T001](t001-bodyweight-history.md); решение [PROGRESS-Q1](../../../../requirements/progress-analytics/open-questions.md), уже применённое в [E025-T003](../../e025-cycle-results/tasks/t003-bodyweight-question.md).

## Критерии готовности

- [ ] Нет ограничения итогами/активным циклом
- [ ] Отправка отличима от подтверждения, ошибка сохраняет текст
- [ ] Повтор одной операции не дублируется
- [ ] Две намеренные разные записи одной даты обрабатываются по принятому правилу
- [ ] Чужие операции закрыты, смена аккаунта не показывает чужой незавершённый ввод
- [ ] Правка/удаление не добавляются как новые возможности.

## Проверка

Пройти описанный сценарий по критериям готовности и сверить наблюдаемый результат с [PRD эпика](../prd.md). Проверить допустимые и недопустимые входы, границы исправлений и сохранность исходных записей там, где они затронуты.

Покрытие приёмки эпика: пункты 2, 3, 5, 6, 8.

В этом PRD «пункт N» означает позицию чекбокса в разделе приёмки, считая сверху с единицы; новая нумерация в PRD не вводится.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре [карточки эпика](../README.md). При выполнении зафиксировать проверенный результат; перед остановкой обновить там текущую точку и конкретное следующее действие.
