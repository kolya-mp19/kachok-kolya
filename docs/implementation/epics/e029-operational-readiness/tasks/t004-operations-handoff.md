# E029-T004. Повторить эксплуатационные процедуры по полной инструкции

## Границы текущего локального этапа

Локальная часть E029 проверяет установку и обновление полной локальной версии, создание резервной копии по команде и восстановление в отдельную локальную БД/тома, диагностику и повтор процедуры по инструкции. Используются синтетические данные, SMTP Mailpit и локальные команды E004/E005/E006-T001; внешние доступы и завершение E003/E006-T002–T003/E010 не нужны. Удалённое размещение, штатное расписание и внешнее хранение копий, эксплуатационные гарантии E003 и выпуск отложены. Локальный протокол фиксируется отдельно от будущей эксплуатационной приёмки; полный E029 и его задачи не объявляются готовыми до выполнения их отложенных критериев.

## Что сделать

Сопровождение может повторить запуск, обновление и восстановление без скрытых знаний автора, выпуск получает конкретное доказательство готовности.

Проверяется конкретная сборка в согласованных условиях; результаты связываются с требованиями и воспроизводимыми примерами. Подготовка задачи не является разрешением на реальные операции выпуска или отправку приглашений.

Локальная реализация по согласованному стеку разрешена. Решения внешней части S01 и доступы применяются только после отдельного разрешения на эксплуатационный этап.

Локальные проверки выполняются в отдельном локальном окружении полной версии [S03–S10](../../README.md), без E010/E009-T004. Используются команды E004/E005 и проверки E006-T001. Работающее хранилище ради проверки не удаляется. Готовность E028 не является блокером.

**Заблокирована:** [E029-T001](t001-install-and-update.md), [E029-T002](t002-backup-restore.md), [E029-T003](t003-failure-recovery.md).

## Критерии локального результата

- [ ] По инструкции повторены локальные запуск, обновление, получение копии и восстановление без скрытых действий автора.
- [ ] Протокол фиксирует сборку, схему, окружение, данные, измерения и ограничения; отложенная внешняя часть явно отделена.

## Отложенные критерии эксплуатационной готовности

- [ ] Инструкция содержит условия/конфигурацию/проверку результата и ссылки на реальные команды без копий
- [ ] Повтор выполнен по тексту, результаты привязаны к сборке/схеме/среде
- [ ] Измерения соответствуют E003 либо расхождения исправлены и перепроверены
- [ ] Ограничения и результат переданы E030, в git только безопасные артефакты.

## Проверка

Пройти описанный сценарий по критериям готовности и сверить наблюдаемый результат с [PRD эпика](../prd.md). Проверить допустимые и недопустимые входы, границы исправлений и сохранность исходных записей там, где они затронуты.

Локальное покрытие PRD: повтор локальных процедур по инструкции и итоговый протокол из раздела «Критерии локального результата».

Покрытие отложенной эксплуатационной приёмки эпика: пункт 8 и итоговая сверка пунктов 1–7.

Здесь «пункт N» означает позицию чекбокса только в разделе «Отложенные критерии эксплуатационной приёмки» PRD, считая сверху с единицы. Номера не относятся к отдельному локальному набору критериев.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре [карточки эпика](../README.md). При выполнении зафиксировать проверенный результат; перед остановкой обновить там текущую точку и конкретное следующее действие.
