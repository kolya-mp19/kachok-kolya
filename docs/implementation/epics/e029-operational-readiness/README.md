# E029. Готовность эксплуатации и восстановление

## Границы текущего локального этапа

Локальная часть E029 проверяет установку и обновление полной локальной версии, создание резервной копии по команде и восстановление в отдельную локальную БД/тома, диагностику и повтор процедуры по инструкции. Используются синтетические данные, SMTP Mailpit и локальные команды E004/E005/E006-T001; внешние доступы и завершение E003/E006-T002–T003/E010 не нужны. Удалённое размещение, штатное расписание и внешнее хранение копий, эксплуатационные гарантии E003 и выпуск отложены. Локальный протокол фиксируется отдельно от будущей эксплуатационной приёмки; полный E029 и его задачи не объявляются готовыми до выполнения их отложенных критериев.

Эпик шага **S11** из [общего плана](../../README.md).
Результат — проверенные выпуск и миграции, настроенное штатное копирование,
проверенное резервное восстановление и инструкция эксплуатации.

- [PRD](./prd.md) — границы, сценарии и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Разбиение согласовано; создано задач: 4. Активной задачи нет.
- Следующее действие после готовности локальных S03–S10: выполнить локальные части T001–T004 и зафиксировать отдельный протокол. Внешние части ждут отдельного разрешения и принятых E003/E006.
- Согласованные решения S01 и конкретные проверки выбранных технологий уточняются до реализации; подготовка задач не заменяет эти входы.

## Зависимости

Локальные входы — обязательные локальные эпики S03–S10 из [реестра](../README.md), без E010/E009-T004, и E006-T001. Полный E006 и согласованный проект эксплуатации E003 требуются только для отложенной внешней приёмки.
Результат передаётся E030; сквозная продуктовая приёмка выполняется E028.

E006 поставляет развёртывание, диагностику и базовую инструкцию. Настройка штатного
копирования по согласованным параметрам E003 и проверка восстановления принадлежат
[E029-T002](./tasks/t002-backup-restore.md); готовый механизм копирования не является её внешним входом.
