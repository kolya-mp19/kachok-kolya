# E011. Сессии и изоляция данных

Эпик шага S04 [общего плана](../../README.md).

- [PRD](./prd.md) — длительная сессия, выход, личная граница дневника и независимый калькулятор.
- [Реестр эпиков](../README.md) — единственное место со статусом эпика.
- **Зависимости:** [E009](../e009-email-access/README.md) в локальной части T001–T003, принятые решения E001/E002 и E005. E010 не блокирует локальную реализацию.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Количество задач: 4; разбивка согласована, файлы созданы; активной задачи нет.
- Следующее действие: после получения входов из зависимостей уточнить проверки по решениям S01
  и начать [E011-T001](./tasks/t001-shared-session.md).
- Локальная реализация разрешена по принятым решениям E001/E002; внешний E003
  и E010 не блокируют её. Конкретные проверки уточняются по PRD перед исполнением.
