# Проверки локального почтового доступа

## Интерфейс T001

Используется согласованный язык E002: фон `#f6f7f9`, поверхность `#ffffff`,
текст `#17212b`, пояснения `#556270`, действие `#2457a7`, граница `#c8d0da`.
Системный sans-serif сохраняет принятые метрики и знакомое поведение менеджера паролей;
заголовки 24/32 и 20/28, основной текст 16/24. Выравнивание по левому краю.

```text
Дневник
План тренировок и записи о выполнении

Регистрация по почте
Имя
[                         ]
Почта
[                         ]
Пароль
[                         ]
[ Отправить письмо        ]
```

Одна форма на всю полезную ширину экрана; ожидание письма и подтверждение заменяют
форму последовательно. Успех показывает пустой дневник с будущим шагом создания
цикла, без кнопки неработающей операции. Проверка плана по brief сохранила токены
и навигацию E002: новая декоративная карточка и собственный акцент здесь не нужны.
Отличительная часть — ясное разделение отправленного письма и подтверждённого
дневника. Ошибка сохраняется рядом с действием, пароль при отказе не стирается.

## Покрытие

`npm run build`, `npm run format:check` и полный `npm test` прошли: 123 теста,
без отказов и пропусков. Отдельный файл регистрации содержит 12 успешных проверок.
Итоговый code-review по Standards и Spec не оставил нерешённых замечаний.
Дополнительный локальный smoke проверил HTTPS Vite с исходным API через tsx,
SMTP, `__Host-session`, Web Crypto AES-GCM и запись IndexedDB. Для него использован
временный синтетический сертификат и разрешение его ошибки в тестовом Chromium;
доверие CA и физические браузеры этим не проверены.

| Область | Проверка | Ограничение |
|---|---|---|
| A1 | Настоящий SMTP Mailpit, GET без создания; атомарный POST, повторы и конкурентные разные письма одной почты | Автоматизированная локальная проверка |
| A5 | Origin/CSRF/браузерная попытка; истечение, назначение, отмена и повтор; SMTP reject и недоступность | Автоматизированная локальная проверка |
| A6 для регистрации | Chromium 320 px, отказ и сохранённый ввод, подтверждение, перезагрузка, текст 200% | Эмуляция не заменяет физические устройства |
| Сессия T001 | Проверка серверной cookie, хешей, повторное открытие дневника | Полная приёмка сессий относится к E011 |
| HTTPS телефона | Конфигурация Vite и [инструкция локального CA](../../../local-email-access.md) | Доверие CA, Secure cookie, API, IndexedDB/Web Crypto на настоящих iOS/Android ещё требуют проверки |
| A2–A4 | Следующие задачи T002/T003 | Не входят в реализацию T001 |

## Оставшаяся приёмка T001

Пройти [протокол на телефоне](../../../local-email-access.md#приёмка-на-устройстве)
в настоящих Safari iOS и Chrome Android. До этой проверки T001 остаётся «В работе»;
локальная реализация регистрации может использоваться следующими задачами.
Внешние провайдеры, SMTP и развёртывание остаются отложенными.
