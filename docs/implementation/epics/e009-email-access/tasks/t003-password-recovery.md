# E009-T003. Восстанавливать пароль прежнего дневника

## Что сделать

**Что даёт:** атлет подтверждает владение почтой из письма и устанавливает новый пароль с сохранением дневника.

Вход — локальные результаты S02 и принятые решения E001/E002. Внешние доступы E003 и развёртывание не блокируют исполнение. Каждый срез включает защищённые операции, хранение, русские мобильные формы и проверку результата. Пароли защищаются Argon2id, токены писем хранятся хешами с назначением и однократным потреблением; сроки действия, повторная отправка и ограничения попыток проверяются локально.

**Заблокирована:** [E009-T002](t002-password-login.md).

## Критерии готовности

- [ ] Запрос письма не меняет пароль; только допустимое подтверждённое действие устанавливает новый.
- [ ] Идентификатор дневника, проверочные записи и существующие способы входа сохранены; проверены отмена, повтор и неуспешное подтверждение.
- [ ] Сбой доставки не меняет доступ; без почты и подключённых способов автоматическое восстановление не обещается.

## Проверка

Получить письмо восстановления в веб-интерфейсе Mailpit и пройти ссылку localhost. Проверить просроченный, использованный и неверного назначения токен, повторную отправку и отказ SMTP; старые сессии после смены пароля отозваны. Сверить идентификатор и записи дневника. Покрытие приёмки эпика: A4–A6.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
