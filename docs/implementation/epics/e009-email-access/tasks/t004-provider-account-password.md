# E009-T004. Устанавливать первый пароль к аккаунту провайдера

**Область выполнения:** задача отложена вместе с E010 до отдельного решения о внешних интеграциях. Не входит в локальную приёмку E009/S04 и не блокирует E011. Приведённые ниже критерии выполняются при возврате к внешнему этапу.

## Что сделать

**Что даёт:** общий механизм восстановления даёт доступ к тому же дневнику, даже если раньше атлет входил только через провайдера.

Вход — локальные результаты S02 и принятые решения E001/E002. Исполнение отложено до возврата к внешним провайдерам. Каждый срез включает защищённые операции, хранение, русские мобильные формы и проверку результата. Пароли защищаются Argon2id, токены писем хранятся хешами с назначением и однократным потреблением; сроки действия, повторная отправка и ограничения попыток проверяются локально.

**Заблокирована:** [E009-T003](t003-password-recovery.md). Возврат к задаче — вместе с внешними провайдерами E010; локальную разработку не блокирует.

## Критерии готовности

- [ ] Подтверждённое письмо устанавливает первый пароль без второго аккаунта и без потери провайдеров или данных.
- [ ] Совпавшее имя, введённая почта и запрос письма не подменяют подтверждение владения.
- [ ] Проверены аккаунты с паролем и без него; интерфейс и механизм подтверждения переданы E010, общий результат входа — E011.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A4–A6; итоговая сверка A1–A3.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
