# E009. Личный дневник и вход по почте

Эпик шага S04 [общего плана](../../README.md).

- [PRD](./prd.md) — регистрация по почте, подтверждение владения и восстановление доступа.
- [Реестр эпиков](../README.md) — единственное место со статусом эпика.
- **Зависимости:** локальные результаты S02 — E004/E005/E006-T001 и принятые решения E001/E002; внешний E003 и E006-T002/T003 не требуются.

## Текущая точка

- Локальные входы S02 и решения E001/E002 получены; реализация регистрации [E009-T001](./tasks/t001-confirmed-email-registration.md) и автоматические проверки выполнены.
- Текущая задача — E009-T001: остаётся приёмка HTTPS с доверенным сертификатом, cookie, API, IndexedDB/Web Crypto на физическом телефоне по [протоколу](./acceptance.md).
- Вход по паролю и безопасная повторная регистрация [E009-T002](./tasks/t002-password-login.md) реализованы и проверены автоматически.
- Следующее действие: продолжить [E009-T003](./tasks/t003-password-recovery.md) и выполнить проверку на устройствах; физическая проверка не заменяется эмуляцией.
- Локальная реализация и необходимые зависимости разрешены; внешние интеграции и развёртывание отложены.

Подключение Mailpit в Docker и проверка SMTP входят в [E009-T001](./tasks/t001-confirmed-email-registration.md).
Письма читаются в веб-интерфейсе Mailpit на loopback машины разработки; ссылки используют настроенный origin приложения. Для проверки на телефоне E009-T001 настраивает HTTPS с локальным доверенным сертификатом без внешних сервисов; E028 повторяет эту проверку.
Внешняя доставка и E010 отложены; для локальной приёмки обязательны только T001–T003.
T004 не начата и возвращается вместе с внешними провайдерами.
