# E028. Сквозная приёмка первой версии

Эпик шага **S11** из [общего плана](../../README.md).
Результат — проверенная совместная работа калькулятора и дневника по действующим требованиям.

- [PRD](./prd.md) — границы, сценарии и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Разбиение согласовано; создано задач: 5. Активной задачи нет.
- Следующее действие: получить необходимые результаты зависимостей и согласованные решения S01, сверить их с PRD и перейти к [E028-T001](./tasks/t001-calculator-acceptance.md).
- Согласованные решения S01 и конкретные проверки выбранных технологий уточняются до реализации; подготовка задач не заменяет эти входы.

## Зависимости

Нужны обязательные эпики S03–S10: E007–E027 из [реестра](../README.md),
согласованные мобильные условия и план проверок E002–E003.
E029 проверяет эксплуатацию, E030 использует результаты обоих эпиков для выпуска.
