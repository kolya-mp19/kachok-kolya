# E002. Мобильные сценарии и визуальный язык

**Шаг:** S01 из [общего плана](../../README.md).

**Документ:** [PRD](./prd.md). Статус эпика ведётся только в
[реестре эпиков](../README.md).

## Текущая точка

- PRD подготовлен; проектирование и реализация эпика не начаты.
- Активной задачи нет; задачи ещё не созданы.
- Следующее действие: детализировать эпик на задачи проектирования мобильных потоков,
  состояний ввода и общего визуального языка.

## Зависимости и результат

Проектируется совместно с [E001](../e001-technical-design/README.md);
завершение согласуется с его архитектурными границами. Условия выпуска передаются
в [E003](../e003-release-design/README.md) в рамках S01.
Входы — [принципы](../../../principles.md) и [бизнес-спеки](../../../requirements/README.md).

Результат — карта мобильных экранов и переходов, состояния ввода и описание визуального
языка для реализации в S02–S10. Технологии интерфейса здесь не выбираются:
стек согласуется с владельцем продукта в E001 до создания проекта и установки зависимостей.

## Задачи

Реестр задач будет заполнен на уровне 3 планирования. Подготовка PRD не означает
выполнения эпика или шага S01.
