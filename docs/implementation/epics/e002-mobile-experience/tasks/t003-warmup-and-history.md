# E002-T003. Спроектировать разминку, отметку подхода и исправление истории

## Что сделать

**Что даёт:** схему выполнения первой тренировки и последующего просмотра и разрешённого исправления её факта.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** [E002-T002](t002-quick-entry.md); проект фиксации плана и исторических условий из [E001-T002](../../e001-technical-design/tasks/t002-manual-plan-and-fact.md)/[E001-T004](../../e001-technical-design/tasks/t004-history-recalculation.md).

## Критерии готовности

- [x] Есть состояния комплекса разминки, пустого комплекса и пропуска разминки с причиной.
- [x] Основной исход подхода отмечается одним касанием, правка происходит на месте, следующее упражнение остаётся видимым.
- [x] История различает план и факт, действительные даты, замену и облегчённое выполнение; запрет изменения плана не запрещает допустимое исправление факта.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A2, A4–A5.

## Результат и продолжение

Подготовлены [схемы разминки, выполнения и истории](../design/warmup-and-history.md):
состояния непустого и пустого комплекса, пропуск с причиной, одно касание и правка
в строке, постоянная область следующего упражнения, отдельные границы фиксации
и допустимые исправления прошлого факта. Критерии проверены проходом схем и примеров
по спекам; фактический мобильный прогон относится к реализации. Следующий результат —
состояния сохранности T004. Состояние задачи ведётся только в реестре карточки эпика.
