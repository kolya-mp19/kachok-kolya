# E002-T001. Спроектировать вход и первый ручной план без МПВ

## Что сделать

**Что даёт:** проверяемую на схемах цепочку от явного выбора дневника через вход и пустое состояние до первого цикла и ручного плана.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** нет; границы уточняются совместно с [E001-T001](../../e001-technical-design/tasks/t001-constraints.md)/[E001-T002](../../e001-technical-design/tasks/t002-manual-plan-and-fact.md) без ожидания завершения E001.

## Критерии готовности

- [x] Показаны провайдеры, запасная почта, подтверждение, восстановление и явное подключение нового способа; калькулятор не требует регистрации.
- [x] Первый цикл не требует истории или МПВ; главная страница ставит положение в цикле выше ближайшей тренировки и описывает отсутствие активного цикла.
- [x] Для каждого экрана определены вход, основное действие, результат и возврат; ограничения мобильного ввода переданы E001 без выбора библиотеки.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A1–A2, часть A8.

## Результат и продолжение

Подготовлены [схемы входа и первого ручного плана](../design/first-manual-plan.md):
провайдеры, почта и восстановление, явное подключение, главный экран и первый цикл,
таблица входов, действий и возвратов экранов, ограничения мобильного ввода для E001.
Критерии проверены сценарным проходом схем; проверки на работающем приложении
относятся к последующей реализации. Следующий результат — подробный ввод T002.
Состояние задачи ведётся только в реестре карточки эпика.
