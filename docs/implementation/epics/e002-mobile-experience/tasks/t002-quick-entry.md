# E002-T002. Спроектировать быстрый ввод и дополнение плана

## Что сделать

**Что даёт:** мобильную схему заполнения длинной недели и дополнения скопированной структуры без весов.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** [E002-T001](t001-first-manual-plan.md) — точка входа в планирование.

## Критерии готовности

- [x] Ввод нотацией показывает разобранные значения до принятия неоднозначности; единицы «кг» и «кг на руку» различимы.
- [x] История упражнения помогает вводу, но её отсутствие его не блокирует; показаны копирование без весов и заполнение недостающего.
- [x] Проверен проход с экранной клавиатурой, длинными названиями и неделей; план, факт и незавершённая правка различимы.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A3, часть A8.

## Результат и продолжение

Подготовлены [схемы быстрого ввода и дополнения плана](../design/quick-entry.md): разбор нотации, предупреждение и ошибка единицы, история рядом с полем, копирование без весов, заполнение недостающего и состояния плана, факта и правки. Сценарный и геометрический проход описан в результате; реальная браузерная проверка относится к реализации. Порог сравнения с историей остаётся [входом E016](../../../../requirements/week-planning/open-questions.md). Продолжение — [E002-T003](./t003-warmup-and-history.md); состояние задачи ведётся в реестре карточки эпика.
