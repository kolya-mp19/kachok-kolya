# E020. История и исправления выполнения

Эпик шага S07 [общего плана](../../README.md).

- [PRD](./prd.md) — история, поздний факт, замены, облегчённое выполнение и состояния тренировок.
- [Реестр эпиков](../README.md) — единственное место со статусом эпика.
- **Зависимости:** [E019](../e019-workout-recording/README.md); согласованные решения S01.

## Текущая точка

PRD подготовлен. Реализация не начата, задачи ещё не созданы.
После завершения зависимостей — сверить контракты истории, дат и исправлений,
затем подготовить задачи эпика. Реестр задач появится здесь при детализации уровня 3.
Дальнейшие пересчёты МПВ, показателей и графиков подключаются в S08–S10.
Технологический стек этим документом не выбирается.
