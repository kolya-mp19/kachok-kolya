# PRD E008. Мобильный сценарий калькулятора

## Результат

Спортсмен открывает страницу с телефона, вводит собственный вес и попытки нескольких
спортсменов и сразу видит рейтинг. Не нужны регистрация, настройка или подтверждение
расчёта. Вычисления предоставляет [E007](../e007-calculator-engine/prd.md), а этот эпик
доводит их до законченного сценария по [calculator](../../../requirements/calculator/index.md).

## Границы

**Входит:** одна страница с карточками, выбором общей формулы и полным рейтингом;
добавление, редактирование, удаление и сворачивание карточек; мгновенный пересчёт,
прочерки для неполных данных, лидеры и пояснение точности при близких итогах.
Все поля и подписи — по-русски, числовой ввод — в килограммах.

**Не входит:** собственная реализация формул (E007), регистрация, данные профиля,
автоподстановка собственного веса, серверные запросы для расчёта, сохранение сессии,
история, экспорт, печать, шаринг, другие дисциплины и фунты. Сессия живёт только
в памяти вкладки; перезагрузка стирает её, включая случай входа в дневник.

Калькулятор — независимый контекст. Общий визуальный язык не создаёт доступа к данным
атлета. Механизм сохранения ввода дневника при потере связи не переносится на сессию
калькулятора и не вводит неоговорённое сохранение в браузере.

## Основной сценарий

1. Открывается одна пустая карточка, выбрана формула Уилкс. Нет кнопки «Рассчитать»
   и требования войти. Данные и рейтинг находятся на одной странице.
2. Спортсмен вводит имя при желании, пол, собственный вес и до трёх попыток.
   Точка и запятая принимаются одинаково; незавершённый ввод не вызывает сообщения об ошибке.
3. Лучшая попытка видна до ввода пола и собственного веса. Остальные величины появляются
   по мере готовности необходимых данных, до этого показываются прочерки.
4. Добавляются новые карточки; заполненные можно свернуть. Последнюю карточку удалить нельзя.
5. Рейтинг сразу обновляется при каждой правке. Строка сохраняет связь с нужной карточкой,
   а безымянный спортсмен обозначен номером своей карточки, например «Спортсмен 3».
6. Смена общей формулы пересчитывает весь рейтинг. Лидеры выделяются одинаково,
   а разные места с одинаковой короткой подписью можно объяснить большей точностью.

## Проект реализации и данные

Вычислительный контракт, правила отсутствующих величин и контрольные сценарии
получены в [передаче расчётного ядра E007](../e007-calculator-engine/engine-handoff.md).
Этот вход не означает реализации или приёмки интерфейса E008.

Состояние страницы содержит список карточек с постоянными идентификаторами и порядком
добавления, текстами числового ввода, именем, полом и признаком свёрнутости; отдельно —
выбранную формулу. Правка или сортировка не меняет идентичность карточки. Тексты ввода
не заменяются нулём при незавершённом числе. Копии вычисленных значений не являются
самостоятельным источником данных: рейтинг выводится из текущего состояния через E007.

Представление отвечает за ввод и короткие подписи; E007 — за числовую трактовку,
формулы, места и лидеров. Вычисленные строки связываются с карточками по идентификаторам.
Вычислительный интерфейс получает карточки и общую формулу, возвращает лучшие попытки,
коэффициенты, итоги, места либо их отсутствие и лидеров.

Все исходные и вычисленные данные остаются в памяти вкладки. Нет API калькулятора,
таблиц спортсменов на сервере, чтения профиля или записи сессии в хранилище браузера.
Используются согласованные React SPA/Vite, Ant Design и Tailwind CSS.
Карточки и полный рейтинг реализуются в отдельной клиентской точке калькулятора;
компоненты не импортируют код сессии и данных дневника.

## Отображение и взаимодействие

Рейтинг содержит место, спортсмена, пол, собственный вес, лучшую попытку, коэффициент
и итог. Порядок строк и места приходят из E007 без повторной сортировки по видимым строкам.
Спортсмены без итога видны после ранжируемых, место у них прочерк. Если итогов нет,
лидеров нет. Неполнота одного спортсмена не прячет и не блокирует других.

Равные итоги выделяются как равные места, без преимущества по полу, весу или имени.
Короткое отображение не меняет вычисления: при итогах `40.004; 40.003` остаются разные
места, даже если подписи совпали. Большая точность и пояснение доступны с телефона;
действие «Показать точнее» раскрывает исходные итоги и пояснение «Места определены до округления».
Короткий итог содержит две десятичные позиции, коэффициент — четыре;
раскрытое значение сохраняет различия чисел `number`, включая экспоненциальную запись.

Доступны Уилкс, «IPF GL — адаптация для бицепса» и DOTS; выбранная формула видна рядом
с рейтингом. IPF GL не выдаётся за официальный зачёт конкретной федерации. Значения
разных формул не сравниваются между собой и не выводятся как общий рейтинг.

Мобильное представление сохраняет доступ ко всем колонкам и полям без перехода
между отдельными экранами ввода и итога. Сворачивание карточек помогает увидеть рейтинг,
а повторное раскрытие возвращает ввод. Отдельный десктопный сценарий не проектируется.

## Зависимости

- E002: согласованный мобильный опыт, навигация и визуальный язык.
- E007: проверенные формулы, контракт вычислений и правила сравнения до округления.
  Основа S02 приходит через зависимость E007; полная приёмка требует готового E007.
- S04 не является зависимостью: калькулятор работает без учётной записи и при наличии
  сессии дневника одинаково. После загрузки страницы расчёты не требуют сервера дневника.
- S11 получает полный сценарий, контрольные примеры E007 и результаты мобильной проверки.

## Критерии приёмки и проверки

- [x] При открытии одна пустая карточка и Уилкс; отсутствуют обязательный вход,
  настройка и кнопка «Рассчитать».
- [x] С телефона можно добавить несколько карточек, заполнить, свернуть, раскрыть
  и удалить нужную. Последняя карточка остаётся; данные не переходят между спортсменами.
- [x] При точке/запятой расчёт одинаков; пустые, нечисловые, нулевые и отрицательные
  значения не вызывают сообщения об ошибке и не блокируют остальные карточки.
- [x] Лучшая попытка видна без пола/веса; остальные значения и места появляются
  по правилам E007. Неконечный расчёт даёт прочерки, а не сломанную страницу.
- [x] Полный рейтинг показывает все поля; безымянные спортсмены узнаваемы по номеру
  карточки, строки без итога остаются в конце без места.
- [x] Итоги `40; 40; 39` показывают места `1; 1; 3` с двумя лидерами;
  `40.004; 40.003` — `1; 2` с одним лидером и доступным пояснением точности.
- [x] Смена формулы сразу меняет значения, места и лидеров; её название видно,
  IPF GL подписан как адаптация для бицепса. Интерфейс целиком на русском.
- [ ] Проверены ввод русской мобильной клавиатурой, чтение рейтинга и исправление
  карточки после смены места; для расчёта не нужен переход на другой экран.
- [x] После загрузки страницы отключение запросов к серверу дневника не мешает вводу
  и расчётам; проверено отсутствие обращений к API и хранилищу дневника.
- [x] Перезагрузка начинает пустую сессию; наличие входа в дневник не сохраняет
  сравнение и не подставляет собственный вес.

[Матрица приёмки](./acceptance.md) связывает отмеченные критерии с браузерными
проверками настоящего E007. Единственный открытый остаток — настоящие клавиатуры
Safari iOS и Chrome Android в позиции 8; эмуляция размеров не закрывает этот пункт.
Наличие cookie и данных дневника проверено синтетическими маркерами без их чтения
калькулятором; это не функциональная приёмка настоящего входа S04.

Проверки включают интеграцию с настоящим ядром E007, наблюдение сетевых обращений
и хранилища, ручную приёмку на мобильном браузере. Главные риски — потеря связи карточки
со строкой при пересортировке, округление как основание места и неявная зависимость
от профиля. Принятая потеря сессии при перезагрузке не считается дефектом.

## Принятые технические решения E001

Калькулятор имеет отдельную клиентскую точку React SPA/Vite с Ant Design и Tailwind CSS. Не
загружает сессию, не вызывает API и не читает черновики дневника даже при выполненном входе. Переход
в дневник остаётся явным.

Основание: [результат E001](../e001-technical-design/design/access-and-trust.md),
[ADR-0020](../../../architecture/adr/ADR-0020-javascript-modular-monolith.md),
[ADR-0021](../../../architecture/adr/ADR-0021-durable-drafts-and-operation-receipts.md).

## Мобильный проект E002

[Калькулятор и визуальный язык E002](../e002-mobile-experience/design/calculator-and-visual-language.md)
задают одну страницу с карточками, тремя попытками, общей формулой и полным рейтингом.
Равные итоги имеют одинаковое место, близкие неравные не уравниваются округлением.
Переход в дневник явный; калькулятор не читает его сессию, API и хранилище.
Проверка схем на узком экране не заменяет реальный браузерный прогон.
