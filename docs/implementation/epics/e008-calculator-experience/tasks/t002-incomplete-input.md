# E008-T002. Продолжать ввод при незавершённых числах и необычных итогах

## Что сделать

**Что даёт:** русская мобильная клавиатура и временная неполнота полей не мешают сравнению остальных спортсменов.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — результаты S02 (завершённые E004–E006), подготовленные на основе согласованного S01. E002 задаёт мобильные сценарии. Все срезы включают русское мобильное представление и проверку с настоящим расчётным контрактом без связи с дневником.

**Заблокирована:** [E008-T001](t001-mobile-comparison.md); проверенные края диапазона [E007-T004](../../e007-calculator-engine/tasks/t004-ranking-boundaries.md).

## Критерии готовности

- [ ] Точка и запятая равнозначны; пустое, текст, ноль, отрицательное и незавершённое число не вызывают сообщения об ошибке и не заменяются фиктивным нулём.
- [ ] Неконечный расчёт даёт прочерки, конечный отрицательный коэффициент не запрещён; остальные карточки продолжают работать.
- [ ] После изменения места можно раскрыть и исправить нужную карточку; ввод и рейтинг остаются на одной странице с открытой клавиатурой.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 3–4, 8. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
