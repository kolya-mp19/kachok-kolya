# E008-T001. Сравнивать несколько спортсменов по Уилксу на одной странице

## Что сделать

**Что даёт:** с телефона пользователь заполняет несколько карточек и сразу видит рейтинг без регистрации и кнопки расчёта.

Согласованные результаты S01 перенесены в [PRD](../prd.md): React SPA/Vite,
Ant Design и Tailwind CSS. Локальные E004, E005 и E006-T001 приняты; E002 задаёт
мобильное представление, E007 передаёт проверенное ядро. Внешние E003 и
E006-T002/T003 локальное исполнение не блокируют; интеграции и выпуск отложены.

Локальных блокеров нет. Источник статуса — реестр задач в карточке эпика.

## Критерии готовности

- [x] При открытии одна пустая карточка и Уилкс; доступны добавление, правка, сворачивание, раскрытие и удаление кроме последней карточки.
- [x] Все поля рейтинга видны, безымянный спортсмен узнаваем по номеру карточки; пересортировка не переносит данные между карточками.
- [x] Лучшая попытка показывается без пола/веса, неполные строки с прочерками остаются в конце; после загрузки расчёт не требует API дневника.

## Проверка

[Браузерный интеграционный тест](../../../../../tests/calculator-experience.test.mjs)
работает с настоящим E007 на ширинах 320/360/390 и высоте 280 CSS-пикселей:
десятичный ввод, лучшая попытка без пола/веса, смена мест без переноса данных и
фокуса, сворачивание/раскрытие, удаление и постоянный номер безымянной карточки.
После добавления фокус на заголовке, следующий Tab ведёт в имя; после удаления —
на соседнюю карточку. Запросы API заблокированы и отсутствуют среди обращений.
Проверяется доступность всех полей рейтинга и отсутствие горизонтальной прокрутки,
включая масштаб текста 200%. Снимки экрана проверены визуально; три попытки
сохраняют доступные подписи, при увеличении текста поля перестраиваются.

Проверка оболочки обновлена под реальный рейтинг вместо заглушки. Типы, сборка
и два браузерных файла проходят; полный прогон выполняется штатным runner
чистого снимка с синтетической PostgreSQL. Покрытие приёмки эпика: позиции 1–2,
4–5, 8–9 в части Уилкса. Реальная экранная клавиатура iOS/Android остаётся
отдельной мобильной приёмкой: эмуляция размеров её не заменяет.

## Результат и продолжение

Реализованы карточки спортсменов и полный рейтинг Уилкса на одной странице.
Ввод остаётся текстом в памяти React, порядок карточек и рейтинга независимы,
результаты вычисляются ядром E007 при каждой правке. Выбранный пол и лидеры
обозначены текстом и знаком вместе с цветом. Последнюю карточку удалить нельзя.
Итоговый независимый review относительно `70c158b`: Standards — 0 оставшихся
замечаний, Spec — 0 оставшихся замечаний. Следующие задачи — края ввода T002,
переключение формул и точность T003, независимость и временность сессии T004.

Полная проверка чистого дерева `6b2435dd272adc8584a0f75dd3c0a47387b8c151`
завершилась успешно: установка по lockfile, Chromium из пользовательского кэша,
синтетическая PostgreSQL, Prisma, форматирование, типы, сборка и 105/105 тестов
без пропусков. Ресурсы проверки очищены. Последующая запись результата проверки
меняет только документацию.
