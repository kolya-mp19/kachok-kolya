# E008-T001. Сравнивать несколько спортсменов по Уилксу на одной странице

## Что сделать

**Что даёт:** с телефона пользователь заполняет несколько карточек и сразу видит рейтинг без регистрации и кнопки расчёта.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Локальная реализация разрешена по согласованному стеку; внешние интеграции и выпуск отложены. Общий вход — локальные результаты S02: E004, E005 и E006-T001. Внешние задачи E003 и E006-T002/T003 локальное исполнение не блокируют. E002 задаёт мобильные сценарии. Все срезы включают русское мобильное представление и проверку с настоящим расчётным контрактом без связи с дневником.

**Заблокирована:** E002; [E007-T001](../../e007-calculator-engine/tasks/t001-wilks-comparison.md).

## Критерии готовности

- [ ] При открытии одна пустая карточка и Уилкс; доступны добавление, правка, сворачивание, раскрытие и удаление кроме последней карточки.
- [ ] Все поля рейтинга видны, безымянный спортсмен узнаваем по номеру карточки; пересортировка не переносит данные между карточками.
- [ ] Лучшая попытка показывается без пола/веса, неполные строки с прочерками остаются в конце; после загрузки расчёт не требует API дневника.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 1–2, 4–5, 8–9 в части Уилкса. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
