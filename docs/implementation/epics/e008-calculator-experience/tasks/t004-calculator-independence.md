# E008-T004. Подтвердить независимость и временность сессии калькулятора

## Что сделать

**Что даёт:** полный мобильный сценарий одинаково работает независимо от состояния дневника и хранится только в памяти вкладки.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — результаты S02 (завершённые E004–E006), подготовленные на основе согласованного S01. E002 задаёт мобильные сценарии. Все срезы включают русское мобильное представление и проверку с настоящим расчётным контрактом без связи с дневником.

**Заблокирована:** [E008-T002](t002-incomplete-input.md), [E008-T003](t003-formula-switching.md).

## Критерии готовности

- [ ] После загрузки отключены запросы к серверу дневника: ввод, формулы и рейтинг работают; API и хранилище дневника не используются.
- [ ] Перезагрузка стирает сравнение; наличие сессии дневника не подставляет собственный вес и не сохраняет карточки в браузере.
- [ ] Пройдена мобильная приёмка с настоящим ядром E007; весь интерфейс русский, все поля доступны без отдельного экрана итога.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 8–10; итоговая сверка 1–7. Полная функциональная приёмка входа дневника остаётся S04, обратной зависимости от него нет. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
