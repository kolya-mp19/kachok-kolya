# E008-T004. Подтвердить независимость и временность сессии калькулятора

## Что сделать

**Что даёт:** полный мобильный сценарий одинаково работает независимо от состояния дневника и хранится только в памяти вкладки.

Согласованный стек S01, мобильный проект E002 и настоящий расчётный контракт E007
получены. Локальные E004/E005 и E006-T001 приняты; внешние интеграции и выпуск
отложены и не блокируют проверку калькулятора.

Реализация и автоматические проверки [T002](t002-incomplete-input.md) и
[T003](t003-formula-switching.md) получены. У T002 остаётся только настоящая
мобильная клавиатура; этот остаток не блокирует автоматическую часть T004.

## Критерии готовности

- [x] После загрузки отключены запросы к серверу дневника: ввод, формулы и рейтинг работают; API и хранилище дневника не используются.
- [x] Перезагрузка стирает сравнение; наличие сессии дневника не подставляет собственный вес и не сохраняет карточки в браузере.
- [ ] Пройдена мобильная приёмка с настоящим ядром E007; весь интерфейс русский, все поля доступны без отдельного экрана итога.

## Проверка

[Два браузерных сценария](../../../../../tests/calculator-independence.test.mjs)
запускаются с настоящим E007 в изолированных контекстах Chromium: пустом и
с синтетической HttpOnly cookie `local-session`, маркерами localStorage,
sessionStorage и IndexedDB `kachok-drafts`. Наблюдение нативных API сохраняет их
поведение и калибруется до загрузки приложения. Калькулятор не читает и не пишет
cookie и хранилища, не вызывает fetch/XHR, не загружает модуль дневника и не
обращается к API. Исходные маркеры и cookie после сценария не меняются.

После загрузки браузер переводится без сети: ввод, добавление, сворачивание,
удаление, три формулы и раскрытие точности работают на той же странице.
Новая вкладка начинает пустое сравнение, сохраняя ввод первой вкладки.
Перезагрузка первой вкладки также возвращает одну пустую карточку без пола,
собственного веса и попыток, формулу Уилкс и рейтинг без места. Статика при новой
загрузке доступна: оффлайн-загрузка приложения не обещается.

Синтетическая cookie не выдаётся за настоящую сессию входа: E009/S04 ещё не
реализованы. Проверена независимость от наличия cookie без её чтения и без
проверки на сервере. Полная приёмка входа остаётся S04 и не создаёт обратной зависимости.

Итоговая [матрица приёмки](../acceptance.md) сопоставляет позиции 1–10 PRD с
наблюдаемыми проверками T001–T004. Позиция 8 и третий критерий этой задачи остаются
открыты только в части настоящих клавиатур Safari iOS и Chrome Android; доступного
устройства в этой сессии нет. Русские подписи, узкие размеры, все поля рейтинга
и исправление карточки без другого экрана подтверждены автоматизацией.

## Результат и продолжение

Независимость и временность сессии подтверждены браузерными регрессиями;
изменение продуктового кода не потребовалось. Следующее действие — пройти
протокол настоящей мобильной клавиатуры в [матрице приёмки](../acceptance.md).
До него T004 и эпик не объявляются полностью принятыми. Внешние интеграции,
удалённая инфраструктура, деплой и выпуск не выполнялись.

Полный прогон чистого дерева `a292554751caca07f7e9010f1f8818c23f045a2d`
прошёл: установка по lockfile, Chromium из пользовательского кэша, синтетическая
PostgreSQL, Prisma, форматирование, типы, сборка, 111/111 тестов без пропусков
и очистка ресурсов. Последующая запись результата меняет только документацию.
Независимый review относительно `e531efd`: Standards — 0 замечаний,
Spec — 0 новых замечаний; известный остаток устройств явно сохранён.
Относительные ссылки изменённых документов проверены: 218/218.
