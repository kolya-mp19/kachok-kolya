# E008-T003. Переключать формулы и объяснять близкие места

## Что сделать

**Что даёт:** одна формула управляет всем рейтингом, а равные короткие подписи не создают ложную ничью.

До исполнения согласованные результаты S01 должны быть перенесены в зависимый PRD; границы, размер задачи и проверки уточняются по выбранным технологиям. Согласование разбивки не означает выбора стека или разрешения создавать проект. Общий блокер — результаты S02 (завершённые E004–E006), подготовленные на основе согласованного S01. E002 задаёт мобильные сценарии. Все срезы включают русское мобильное представление и проверку с настоящим расчётным контрактом без связи с дневником.

**Заблокирована:** [E008-T001](t001-mobile-comparison.md); [E007-T004](../../e007-calculator-engine/tasks/t004-ranking-boundaries.md).

## Критерии готовности

- [ ] Доступны Уилкс, «IPF GL — адаптация для бицепса» и DOTS, название общей формулы видно; переключение меняет все величины, места и лидеров.
- [ ] Для истинной ничьей лидеры выделены одинаково; при разных точных итогах с одинаковой подписью доступна большая точность и пояснение с телефона.
- [ ] Проверены примеры `40; 40; 39` и `40.004; 40.003`; порядок не пересчитывается по видимым строкам.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: позиции 6–8. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализация не начата. После получения входных результатов уточнить технические проверки по согласованному PRD; при выполнении зафиксировать проверенный результат и оставшиеся действия. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
