# E008-T003. Переключать формулы и объяснять близкие места

## Что сделать

**Что даёт:** одна формула управляет всем рейтингом, а равные короткие подписи не создают ложную ничью.

Согласованные результаты S01, мобильный проект E002 и контракт E007 перенесены в PRD.
Локальная реализация использует React SPA/Vite, Ant Design и Tailwind CSS;
внешние интеграции и выпуск отложены. Локальные зависимости получены.

**Зависимости получены:** [E008-T001](t001-mobile-comparison.md),
[E007-T004](../../e007-calculator-engine/tasks/t004-ranking-boundaries.md).

## Критерии готовности

- [x] Доступны Уилкс, «IPF GL — адаптация для бицепса» и DOTS, название общей формулы видно; переключение меняет все величины, места и лидеров.
- [x] Для истинной ничьей лидеры выделены одинаково; при разных точных итогах с одинаковой подписью доступна большая точность и пояснение с телефона.
- [x] Проверены примеры `40; 40; 39` и `40.004; 40.003`; порядок не пересчитывается по видимым строкам.

## Проверка

[Браузерные проверки](../../../../../tests/calculator-formula-switching.test.mjs)
используют настоящий E007 и подготовленные попытки из
[передачи ядра](../../e007-calculator-engine/engine-handoff.md): для каждой формулы
проверены места `1; 1; 3`, одинаковое выделение двух лидеров, места `1; 2`
при коротких подписях `40,00` и раскрытие `40,004; 40,003`.
Отдельный пример проверяет смену лидера, коэффициентов и итогов между формулами,
сохранение свёрнутой карточки, значений и фокуса выбора.
Проверены ширины 320/360/390 при высоте 280 CSS-пикселей и масштаб текста 200%.
Это браузерная автоматизация, а не подтверждение работы настоящих клавиатур iOS/Android.
Покрытие приёмки эпика: позиции 6–7 и часть 8.

## Результат и продолжение

Одна формула управляет всем сравнением. Рейтинг подписан выбранной формулой;
«Показать точнее» раскрывает исходные итоги и пояснение «Места определены до округления».
Представление не сортирует строки заново. Следующая задача —
[E008-T004](./t004-calculator-independence.md), проверка независимости и временности сессии.
Проверка типов, сборка и целевые браузерные сценарии прошли. Полный штатный прогон
чистого снимка `40134ec3663e9198fb22c0aecd8baad56aa786e3` завершился успешно:
109/109 тестов без пропусков, все этапы и очистка тестового окружения прошли.
Независимые оси review: Standards — 0 замечаний, Spec — 0 замечаний.
Относительные ссылки документации проверены: 54/54.
