# E008. Мобильный сценарий калькулятора

Эпик шага **S03** из [общего плана](../../README.md).
Результат — готовая анонимная страница сравнения спортсменов на телефоне.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- [E008-T001](./tasks/t001-mobile-comparison.md) реализована: карточки и полный рейтинг Уилкса работают на одной странице через настоящее ядро E007.
- Согласованные решения S01 и мобильный проект E002 перенесены в PRD; локальные зависимости готовы.
- [E008-T002](./tasks/t002-incomplete-input.md): реализация и автоматические проверки краёв ввода завершены; чистый снимок — 107/107 тестов, независимый review без замечаний к изменению. Остался только прогон с настоящими клавиатурами Safari iOS и Chrome Android; доступного устройства в этой сессии нет.
- [E008-T003](./tasks/t003-formula-switching.md) реализована: переключение трёх формул и раскрытие точных итогов проверены с настоящим E007; чистый снимок — 109/109 тестов, Standards 0, Spec 0.
- Автоматическая часть [E008-T004](./tasks/t004-calculator-independence.md) подтверждает независимость от API, cookie и хранилищ дневника, работу расчётов без сети после загрузки и пустое сравнение после reload или в новой вкладке. Чистый снимок — 111/111 тестов без пропусков, Standards 0, Spec 0 новых замечаний. Продуктовая реализация и автоматическая приёмка E008 получены.
- Единственный остаток T002/T004 и [приёмки PRD](./acceptance.md) — настоящие русские клавиатуры Safari iOS и Chrome Android. Устройства в этой сессии недоступны; размеры 320/360/390 × 280, масштаб текста 200% и посимвольный ввод их не заменяют. Следующее действие — протокол устройств в матрице приёмки; до него эпик и S03 не завершаются.
- Локальная реализация и необходимые зависимости разрешены по согласованному стеку; внешние интеграции и выпуск отложены.

## Зависимости

E002 задаёт согласованный мобильный опыт и общий визуальный язык; основа S02 приходит
через зависимость E007. [E007](../e007-calculator-engine/README.md)
предоставляет вычисления и рейтинг. Вход и данные дневника не требуются. S11 получает
готовый сценарий и результаты мобильной приёмки.
