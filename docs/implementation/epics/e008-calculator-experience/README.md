# E008. Мобильный сценарий калькулятора

Эпик шага **S03** из [общего плана](../../README.md).
Результат — готовая анонимная страница сравнения спортсменов на телефоне.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Активной задачи нет; разбивка согласована, создано задач: 4.
- Следующее действие: получить результаты зависимостей, перенести согласованные решения S01 в PRD и уточнить проверки [E008-T001](./tasks/t001-mobile-comparison.md) перед исполнением.
- Локальная реализация и необходимые зависимости разрешены по согласованному стеку; внешние интеграции и выпуск отложены.

## Зависимости

E002 задаёт согласованный мобильный опыт и общий визуальный язык; основа S02 приходит
через зависимость E007. [E007](../e007-calculator-engine/README.md)
предоставляет вычисления и рейтинг. Вход и данные дневника не требуются. S11 получает
готовый сценарий и результаты мобильной приёмки.
