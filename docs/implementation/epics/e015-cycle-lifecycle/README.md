# E015. Календарь и жизненный цикл цикла

Эпик шага **S06** из [общего плана](../../README.md).
Результат — создание цикла из шаблона, календарные переходы, прерывание и положение в цикле.

- [PRD](./prd.md) — границы, проект реализации и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задач нет; их реестр и каталог появятся при детализации уровня 3.
- Следующее действие: после S05 уточнить согласованные решения S01 и подготовить задачи эпика.

## Зависимости

S05 (E012–E014) предоставляет упражнения и залы; техническая основа приходит из S01/S02.
[E016](../e016-plan-entry/README.md) и [E017](../e017-plan-management/README.md)
используют недели и ограничения цикла. Расчётные подсказки подключаются в S08,
показатели и итоговые экраны — в S09; эти интеграции не блокируют реализацию календаря.
