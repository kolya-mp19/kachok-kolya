Эпик шага S05 [общего плана](../../README.md). Результат и приёмка описаны в
[PRD](./prd.md); статус ведётся в [реестре эпиков](../README.md).

## Текущая точка

- PRD подготовлен; реализация не начата.
- Количество задач: 3; разбивка согласована, файлы созданы; активной задачи нет.
- Следующее действие: после получения входов из зависимостей уточнить проверки по решениям S01
  и начать [E013-T001](./tasks/t001-explicit-exercise-link.md).
- Подготовка задач не согласует стек: до реализации результаты S01 переносятся в PRD,
  конкретные проверки уточняются по выбранным технологиям.

## Зависимости

- [E012](../e012-exercise-catalog/README.md): идентификаторы, единица веса и личные свойства.
- Решения S01 о данных и изменениях согласуются с владельцем проекта до реализации.
- S07 сохраняет принадлежность факта; S08 подключает МПВ и предписания; S10 — графики.
  Их отсутствие не блокирует S05, но полная приёмка поздних интеграций обязательна.
- [E023-T001](../e023-progression-and-return/tasks/t001-weight-selection.md) подключает выбор текущих типа прибавки и подбора к окну связи, включая обе стороны переустановки; [E021-T004](../e021-max-history/tasks/t004-linked-max-preview.md) — МПВ и пересмотры. Это обязанности поздних потребителей, а не блокеры задач E013.
