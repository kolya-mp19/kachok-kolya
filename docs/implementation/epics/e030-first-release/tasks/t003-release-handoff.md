# E030-T003. Передать работающую версию в сопровождение

## Границы текущего локального этапа

Весь эпик отложен: текущий результат проекта — приложение для локальной работы, без удалённого развёртывания, внешних интеграций и открытия доступа аудитории. Задачи и критерии ниже относятся только к будущему выпуску после отдельного разрешения владельца. Локальная приёмка E028 и локальное восстановление E029 не требуют начала или завершения E030.

## Что сделать

Понятны реальное состояние выпуска, доступные процедуры диагностики/копий/восстановления и следующее конкретное действие.

Проверяется конкретная сборка в согласованных условиях; результаты связываются с требованиями и воспроизводимыми примерами. Подготовка задачи не является разрешением на реальные операции выпуска или отправку приглашений.

Перед выполнением согласованные решения [S01](../../../README.md) должны быть перенесены в PRD; технологии и конкретные проверки уточняются по этим решениям. Подготовка задач не означает согласования технологического стека или начала реализации.

Эти задачи описывают будущие действия, подготовка предложения не является разрешением
на развёртывание, открытие доступа или отправку приглашений.

**Заблокирована:** [E030-T002](t002-deploy-and-open-access.md).

## Критерии готовности

- [ ] Актуальные версии/проверки/ограничения зафиксированы, сопровождающий имеет доступ к процедурам и механизмам
- [ ] Текущие точки и статусы общего плана/эпиков соответствуют выполненному
- [ ] Новые пожелания не выданы за дефекты, отложенное не отмечено выполненным
- [ ] Секретов и реальных проверочных записей в git нет.

## Проверка

Пройти описанный сценарий по критериям готовности и сверить наблюдаемый результат с [PRD эпика](../prd.md). Проверить допустимые и недопустимые входы, границы исправлений и сохранность исходных записей там, где они затронуты.

Покрытие приёмки эпика: пункты 7, 8.

В этом PRD «пункт N» означает позицию чекбокса в разделе приёмки, считая сверху с единицы; новая нумерация в PRD не вводится.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре [карточки эпика](../README.md). При выполнении зафиксировать проверенный результат; перед остановкой обновить там текущую точку и конкретное следующее действие.
