# E030. Выпуск для согласованной аудитории

## Границы текущего локального этапа

Весь эпик отложен: текущий результат проекта — приложение для локальной работы, без удалённого развёртывания, внешних интеграций и открытия доступа аудитории. Задачи и критерии ниже относятся только к будущему выпуску после отдельного разрешения владельца. Локальная приёмка E028 и локальное восстановление E029 не требуют начала или завершения E030.

Эпик шага **S11** из [общего плана](../../README.md).
Результат — принятая первая версия доступна согласованной аудитории и готова к сопровождению.

- [PRD](./prd.md) — условия выпуска, границы и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Разбиение согласовано; создано задач: 3. Активной задачи нет.
- Активных действий нет. После отдельного разрешения на выпуск получить внешние результаты E003/E006/E010/E029, дополнить локальную приёмку внешней матрицей и перейти к [E030-T001](./tasks/t001-release-decision.md).
- Согласованные решения S01 и конкретные проверки выбранных технологий уточняются до реализации; подготовка задач не заменяет эти входы.
- До доступа первого незнакомого атлета проверить выполнение [условия удаления аккаунта](../../../backlog.md); выпуск выполняется в пределах явной авторизации.
