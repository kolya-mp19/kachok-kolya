# E018. Разминочные комплексы и выполнение разминки

Эпик шага S07 [общего плана](../../README.md).

- [PRD](./prd.md) — личные комплексы, отметки, сохранённая разминка и её индикатор.
- [Реестр эпиков](../README.md) — единственное место со статусом эпика.
- **Зависимости:** S06 — E015–E017; согласованные с владельцем проекта решения S01.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Количество задач: 4; разбивка согласована, файлы созданы; активной задачи нет.
- Следующее действие: после получения входов из зависимостей уточнить проверки по решениям S01
  и начать [E018-T001](./tasks/t001-personal-warmup-complex.md).
- Подготовка задач не согласует стек: до реализации результаты S01 переносятся в PRD,
  конкретные проверки уточняются по выбранным технологиям.
