# E018. Разминочные комплексы и выполнение разминки

Эпик шага S07 [общего плана](../../README.md).

- [PRD](./prd.md) — личные комплексы, отметки, сохранённая разминка и её индикатор.
- [Реестр эпиков](../README.md) — единственное место со статусом эпика.
- **Зависимости:** S06 — E015–E017; согласованные с владельцем проекта решения S01.

## Текущая точка

PRD подготовлен. Реализация не начата, задачи ещё не созданы.
После завершения зависимостей — уточнить контракты тренировки и фиксации комплекса,
затем подготовить задачи эпика. Реестр задач появится здесь при детализации уровня 3.
Индикатор проверяется на подготовленных данных здесь, с реальным фактом — в E019–E020.
Технологический стек этим документом не выбирается.
