# E018-T004. Читать собственный индикатор разминки на тренировке

## Что сделать

Атлет видит долю выполненных разминок среди тренировок цикла с фактом и непустым сохранённым комплексом, отдельно от достижения индивидуальных целей.

Представление индивидуальных целей и результатов разминочных упражнений принадлежит
[E018-T002](./t002-warmup-mark-and-skip.md). Эта задача считает долю явных отметок
выполнения разминки, а не степень достижения индивидуальных целей.

До реализации согласованные результаты S01 необходимо перенести в зависимые PRD
и уточнить конкретные проверки выбранных технологий. Создание этих задач не означает
согласования стека или начала реализации.

Срез включает хранение, защищённые операции и мобильное русское представление.
Для проверки раннего контракта допустимы проверочные источники истории: поздние
расчёты и потребители подключаются в своих эпиках без обратной зависимости.

## Входные условия эпика

Общий вход: [S06](../../README.md) — тренировка, копирование, события календаря
и фиксации. Реальные подходы подключает E019; до него используются проверочные события.

**Заблокирована:** [E018-T003](./t003-warmup-snapshot.md).

## Критерии готовности

- [ ] 4/5 даёт 80%, пустой знаменатель — прочерк.
- [ ] Любая отмеченная попытка учитывается, пустые комплексы и разминка без подходов нет.
- [ ] Вне своей недели участие сохраняется.
- [ ] Исправления, пропуск и снятие подходов пересчитывают результат.
- [ ] Индикатор не попадает в сводку цикла, все подписи по-русски.
- [ ] Сценарий проверен с телефона; операции и личные данные изолированы между двумя атлетами.

## Проверка

Пройти описанный пользовательский сценарий и его граничные случаи с проверкой
сохранённого результата, ошибок, повторной операции и доступа другого атлета.
Поздние интеграции проверять в эпиках-потребителях; проверочные данные не считать
реализованным спортивным расчётом.

Покрытие приёмки эпика: пункты 6–7, 9; пункт 8 (индивидуальные цели и результаты) покрывает [E018-T002](./t002-warmup-mark-and-skip.md). Пункты отсчитываются по порядку чекбоксов основного раздела приёмки PRD; это не идентификаторы A#.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре карточки
эпика. При выполнении уточнить PRD по согласованным решениям; перед остановкой
обновить там текущую точку и следующее действие.
