# E018-T002. Отметить выполнение или пропуск разминки и открыть основную часть

## Что сделать

Атлет видит индивидуальные цели и результаты разминочных упражнений, отмечает выполнение
или пропуск и переходит к основной части. Верхний блок сворачивается после отметки,
пропуск с причиной виден в истории; снятие отметки не стирает факт и разрешённые исправления.

До реализации согласованные результаты S01 необходимо перенести в зависимые PRD
и уточнить конкретные проверки выбранных технологий. Создание этих задач не означает
согласования стека или начала реализации.

Срез включает хранение, защищённые операции и мобильное русское представление.
Для проверки раннего контракта допустимы проверочные источники истории: поздние
расчёты и потребители подключаются в своих эпиках без обратной зависимости.

## Входные условия эпика

Общий вход: [S06](../../README.md) — тренировка, копирование, события календаря
и фиксации. Реальные подходы подключает E019; до него используются проверочные события.

**Заблокирована:** [E018-T001](./t001-personal-warmup-complex.md).

## Критерии готовности

- [ ] Причина обязательна для пропуска.
- [ ] До старта цикла отметки недоступны, поздние даты ограничены датой прерывания.
- [ ] Без отметки непустого комплекса закрыты только новые подходы.
- [ ] Необязательные результаты и недобор цели не мешают выполнению.
- [ ] Цель и фактические результаты показаны отдельно для каждого разминочного упражнения выбранной тренировки, например «20/20/17 из 3 по 20»; без цели виден только факт.
- [ ] Минуты и повторения не объединяются в общий процент достижения целей. Недобор не подсвечивается, достижение цели отмечается тихо; отсутствие необязательных результатов не отменяет отметку выполнения.
- [ ] Сценарий проверен с телефона; операции и личные данные изолированы между двумя атлетами.

## Проверка

Пройти описанный пользовательский сценарий и его граничные случаи с проверкой
сохранённого результата, ошибок, повторной операции и доступа другого атлета.
Поздние интеграции проверять в эпиках-потребителях; проверочные данные не считать
реализованным спортивным расчётом.

Проверить упражнения с целями в минутах и повторениях в одном комплексе, результат
«20/20/17 из 3 по 20», достижение цели, отсутствие цели и отсутствие необязательных
результатов. Во всех случаях явная отметка выполнения и допуск к основной части
не зависят от достижения цели. Общую долю выполненных разминок проверяет
[E018-T004](./t004-warmup-indicator.md).

Покрытие приёмки эпика: пункты 3, 5 (снятие), 8. Пункты отсчитываются по порядку чекбоксов основного раздела приёмки PRD; это не идентификаторы A#.

## Результат и продолжение

Результат ещё не подготовлен. Состояние задачи ведётся только в реестре карточки
эпика. При выполнении уточнить PRD по согласованным решениям; перед остановкой
обновить там текущую точку и следующее действие.
