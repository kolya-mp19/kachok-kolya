# E006-T001. Получать воспроизводимый итог проверки изменения

## Границы текущего локального этапа

Локальный выход E006 — выполненная E006-T001: воспроизводимые проверки из чистой копии без внешних сервисов и полномочий выпуска. Он достаточен для локального S02 и зависимых продуктовых эпиков; завершение E003/S01 не требуется. E006-T002/T003 и критерии развёртывания/эксплуатации ниже отложены до отдельного разрешения. Полный E006 не объявляется готовым по одной T001. Диагностика локальных сбоев и безопасные миграции остаются обязательными в E004/E005 и локальной приёмке E029.

## Что сделать

**Что даёт:** определённое состояние git проверяется в чистом окружении теми же обязательными командами, что локально.

Используются согласованный стек E001/E002 и принятые E004/E005. Локальная реализация разрешена; завершение E003 и внешние доступы не нужны.

**Входы:** принятые E001/E002/E004/E005; локальные команды запуска и миграций. Внешнего блокера нет.

## Критерии готовности

- [x] Установка зависимостей, обязательные проверки и подготовка приложения повторяемы и прослеживаются до состояния git.
- [x] Намеренно ошибочное изменение даёт неуспех, исправленное — успех; этапы и причины различимы.
- [x] Проверки выполняются локально из чистой копии отслеживаемых файлов с установкой по lockfile, генерацией Prisma Client, проверкой типов, тестами и сборкой; используется отдельная синтетическая БД, а добавляемая почта направляется только в Mailpit.
- [x] Локальные команды документированы; обычная проверка не получает полномочия развёртывания без необходимости, секреты не раскрываются.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие локальной приёмки эпика: позиции 1–4 и локальные части 9–10; отложенные критерии развёртывания не входят в готовность T001. «Позиция N» — N-й чекбокс основного раздела приёмки PRD; исходные критерии не имеют A-идентификаторов.

## Результат и продолжение

Реализована команда `npm run check -- --ref <commit-or-tree>`; порядок этапов,
изоляция и диагностика описаны в [инструкции](../checks.md). Браузеры Playwright
используют общий пользовательский кэш и повторно не скачиваются при наличии нужной версии.

Чистый снимок `e93f02ac0d43124df7e6adca2d106a1fb5e68861` прошёл установку по lockfile,
генерацию Prisma Client, форматирование, проверку типов, сборку и 63/63 теста
без пропусков. Итог процесса — 0; очистка временной PostgreSQL и исходников успешна.
Контрольный снимок с ошибкой типов остановился на `typecheck` с TS2322 и итогом 1;
сборка и тесты после отказа не запускались, очистка выполнена.
Переданные родительскому процессу контрольные адрес внешней БД и токен выпуска
не использовались и отсутствуют в диагностике. Повторный успешный прогон использовал
установленный Chromium без загрузки.

Локальный вход для зависимых продуктовых эпиков получен. T002/T003 и весь E006
не объявляются завершёнными. Состояние задачи ведётся только в реестре карточки эпика.
