# E006. Автоматические проверки и тестовое развёртывание

## Границы текущего локального этапа

Локальный выход E006 — выполненная E006-T001: воспроизводимые проверки из чистой копии без внешних сервисов и полномочий выпуска. Он достаточен для локального S02 и зависимых продуктовых эпиков; завершение E003/S01 не требуется. E006-T002/T003 и критерии развёртывания/эксплуатации ниже отложены до отдельного разрешения. Полный E006 не объявляется готовым по одной T001. Диагностика локальных сбоев и безопасные миграции остаются обязательными в E004/E005 и локальной приёмке E029.

Эпик шага **S02 «Подготовить работающую основу приложения»** из
[общего плана](../../README.md). Объём и приёмка — в [PRD](./prd.md).
Статус ведётся только в [реестре эпиков](../README.md).

## Текущая точка

- Локальная [E006-T001](./tasks/t001-automated-checks.md) принята: чистый снимок, обязательные проверки и 63/63 теста без пропусков; контрольная ошибка типов даёт неуспех.
- Активной разрешённой задачи нет; T002/T003 остаются отложенными. Полный E006 не завершён.
- Следующее действие: использовать [локальную автопроверку](./checks.md) в продуктовых эпиках; возвращаться к T002 после отдельного разрешения внешних работ и завершения E003.
- Локальная реализация по согласованному стеку разрешена; внешняя часть остаётся отложенной.

## Зависимости и результат

Локальные входы — принятые E001/E002, локальный запуск E004 и миграции E005. Для отложенных развёртывания и эксплуатационной приёмки дополнительно требуется завершённый E003.

Выход — автоматическая проверка изменений, воспроизводимое тестовое развёртывание,
диагностика ошибок и инструкция. Это основа последующей разработки; публичный выпуск
и проверка эксплуатационной готовности всей первой версии остаются в S11.

Перед остановкой работы текущая точка дополняется ссылкой на задачу и конкретным действием для продолжения.
