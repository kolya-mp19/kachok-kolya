# E006. Автоматические проверки и тестовое развёртывание

Эпик шага **S02 «Подготовить работающую основу приложения»** из
[общего плана](../../README.md). Объём и приёмка — в [PRD](./prd.md).
Статус ведётся только в [реестре эпиков](../README.md).

## Текущая точка

- PRD подготовлен; реализация не начата.
- Задачи ещё не созданы; активной задачи нет.
- Следующее действие: после согласования с пользователем решений S01 и подготовки
  [E004](../e004-project-foundation/README.md) и [E005](../e005-storage-foundation/README.md)
  разбить эпик на задачи с конкретными командами и параметрами выбранного окружения.
- До согласования S01 проект не создаётся и зависимости не устанавливаются.

## Зависимости и результат

Вход — завершённый **E003** и согласованные решения S01 о проверках, размещении, окружениях, диагностике
и восстановлении; локальный запуск E004 и миграции E005. Подготовка автоматических
проверок может начаться после E004, но приёмка развёртывания требует и E005.

Выход — автоматическая проверка изменений, воспроизводимое тестовое развёртывание,
диагностика ошибок и инструкция. Это основа последующей разработки; публичный выпуск
и проверка эксплуатационной готовности всей первой версии остаются в S11.

Реестр задач появится здесь при отдельной детализации. Перед остановкой работы текущая
точка дополняется ссылкой на задачу и конкретным действием для продолжения.
