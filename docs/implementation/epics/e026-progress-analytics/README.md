# E026. Динамика упражнений и сравнение недель

Эпик шага **S10** из [общего плана](../../README.md).
Результат — понятная динамика отдельных упражнений и сравнение сопоставимых недель.

- [PRD](./prd.md) — границы, данные, проверки и критерии приёмки.
- [Реестр эпиков](../README.md) — единственный источник статуса эпика.

## Текущая точка

- PRD подготовлен; реализация не начата.
- Разбиение согласовано; создано задач: 5. Активной задачи нет.
- Следующее действие: получить необходимые результаты зависимостей и согласованные решения S01, сверить их с PRD и перейти к [E026-T001](./tasks/t001-initial-progress.md).
- Согласованные решения S01 и конкретные проверки выбранных технологий уточняются до реализации; подготовка задач не заменяет эти входы.

## Зависимости

[E024](../e024-cycle-metrics/README.md) предоставляет показатели соблюдения,
[E025](../e025-cycle-results/README.md) — итоги и переходы к исходным данным.
Через них доступны история S07 и расчёты МПВ/предписаний S08.
Стек и способы построения интерфейса следуют согласованным с владельцем решениям S01.
