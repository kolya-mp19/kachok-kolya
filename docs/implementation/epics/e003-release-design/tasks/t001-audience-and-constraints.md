# E003-T001. Согласовать аудиторию и эксплуатационные ограничения

## Границы текущего локального этапа

Внешние интеграции, удалённые окружения, DNS/TLS, доступы к серверу, внешней почте и приложениям Яндекс/VK отложены. E003/S01 остаются незавершёнными; отсутствие внешних доступов блокирует только отложенную внешнюю часть, а не локальную разработку и приёмку. Принятые проектные результаты T001/T003 и локально применимые правила безопасности, диагностики и восстановления используются без ожидания завершения T002/T004/T005. Возврат к внешним операциям требует отдельного разрешения владельца.

## Что сделать

**Что даёт:** конкретные условия первого доступа и ограничения для выбора технической основы.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** нет; согласование с владельцем начинается параллельно с [E001-T001](../../e001-technical-design/tasks/t001-constraints.md).

## Критерии готовности

- [x] Определены аудитория, способ доступа, условия сопровождения и ответственный за выпуск; бюджет исключён из проектирования по прямому указанию владельца.
- [x] Применимость триггера удаления аккаунта до первого незнакомого атлета явная; если применим, дополнительная продуктовая работа вынесена в требования до выпуска без изобретения потока здесь.
- [x] В E001 переданы ограничения внешних доступов и ожидания по сохранности и восстановлению; согласование не требует выбранного хостинга.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A1, вход для A6 и A8.

## Результат и продолжение

Результат — [проектный документ](../design/audience-and-constraints.md). Аудитория и условия доступа определены; бюджет исключён по указанию владельца. Ограничения переданы в E001.
Состояние и следующее действие ведутся в [карточке эпика](../README.md).
