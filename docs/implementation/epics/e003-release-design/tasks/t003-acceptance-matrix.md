# E003-T003. Согласовать матрицу проверок первой версии

## Что сделать

**Что даёт:** проверяемый маршрут приёмки каждой бизнес-спеки на выбранных мобильных браузерах.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** [E003-T001](t001-audience-and-constraints.md); от E002 нужны схемы основных потоков и ограничения клавиатуры, а не итоговая сдача E002.

## Критерии готовности

- [ ] Каждая бизнес-спека, включая калькулятор, сопоставлена с эпиком, автоматической или ручной проверкой и наблюдаемым результатом.
- [ ] Есть детерминированные расчётные и календарные примеры, изоляция, восстановление доступа, первый дневник без МПВ, копия без весов, разминка и исправления истории.
- [ ] С владельцем определены мобильные браузеры и условия ввода, потери связи и истечения сессии; эпики проверяются до завершения, S11 проверяет совместную работу.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A3–A4.

## Результат и продолжение

Проектный результат ещё не подготовлен. При выполнении записать согласованные решения в PRD и, когда применимо, ADR. Состояние задачи ведётся только в реестре карточки эпика; перед остановкой там обновляются текущая точка и следующее действие.
