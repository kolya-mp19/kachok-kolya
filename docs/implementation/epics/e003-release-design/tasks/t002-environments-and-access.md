# E003-T002. Спроектировать окружения и безопасные внешние доступы

## Что сделать

**Что даёт:** воспроизводимый проект получения окружений и конфигурации, по которому S02 подключит инфраструктуру.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** [E003-T001](t001-audience-and-constraints.md); согласованный стек [E001-T005](../../e001-technical-design/tasks/t005-technology-stack.md) и проект доступа [E001-T006](../../e001-technical-design/tasks/t006-access-and-trust.md).

## Критерии готовности

- [x] Определены локальное, тестовое и рабочее окружения, разделение данных, ответственные за размещение, почту и провайдеров, необходимость домена.
- [ ] Возможность подключения выбранных сервисов проверена; порядок предоставления секретов описан без значений в git.
- [x] Тестовое окружение не использует рабочий дневник и не отправляет настоящим атлетам тестовые письма восстановления; аккаунты поставщиков в этой задаче не создаются.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A2, часть A8.

## Результат и продолжение

Результат — [проектный документ](../design/environments-and-access.md). Окружения, ответственные и передача секретов спроектированы. Фактическая возможность подключения домена, почты и кабинетов ещё не подтверждена; критерий подключения остаётся открытым.
Состояние и следующее действие ведутся в [карточке эпика](../README.md).
