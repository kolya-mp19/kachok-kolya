# E003-T004. Спроектировать выпуск и восстановление данных

## Границы текущего локального этапа

Внешние интеграции, удалённые окружения, DNS/TLS, доступы к серверу, внешней почте и приложениям Яндекс/VK отложены. E003/S01 остаются незавершёнными; отсутствие внешних доступов блокирует только отложенную внешнюю часть, а не локальную разработку и приёмку. Принятые проектные результаты T001/T003 и локально применимые правила безопасности, диагностики и восстановления используются без ожидания завершения T002/T004/T005. Возврат к внешним операциям требует отдельного разрешения владельца.

## Что сделать

**Что даёт:** согласованный порядок выпуска и восстановления с измеримыми условиями успешности.

Результат — согласованные документы и схемы. Код приложения, стартовый проект, зависимости, инфраструктура и подключение внешних аккаунтов в задачу не входят. Ранние ограничения уточняются совместно с владельцем без ожидания завершения соседнего эпика.

**Заблокирована:** [E003-T002](t002-environments-and-access.md); проект сохранности [E001-T007](../../e001-technical-design/tasks/t007-input-preservation.md).

## Критерии готовности

- [x] Описаны проверки, сборка, миграции, установка, проверка работоспособности и действия при неудаче.
- [x] С владельцем согласованы состав, периодичность и хранение копий, допустимая потеря данных, срок восстановления и сценарий проверки сохранности дневника.
- [x] Согласованный проект копирования передан в [E029-T002](../../e029-operational-readiness/tasks/t002-backup-restore.md), которая настраивает штатный механизм и проверяет восстановление полной версии; подготовка проекта не выдаётся за работающие копии.
- [x] Возврат версии отделён от восстановления данных; для изменения схемы предусмотрен путь к совместимому состоянию без предположения об обратимости любой миграции.

## Проверка

Пройти описанный сценарий и проверить каждый критерий готовности на наблюдаемом результате. Покрытие приёмки эпика: A5–A6.

## Результат и продолжение

Результат — [проектный документ](../design/release-and-recovery.md). Выпуск, совместимость миграций и восстановление спроектированы; параметры копий и контроль дневника переданы в E029. Приёмка зависит от внешних входов T002; работающий механизм не заявлен.
Состояние и следующее действие ведутся в [карточке эпика](../README.md).
