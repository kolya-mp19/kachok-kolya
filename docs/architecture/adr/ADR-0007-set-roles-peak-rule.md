# У подхода есть роль; определяется правилом пика

Каждый подход имеет роль: **разминочный**, **рабочий**, **добивающий** или **отказной**.
Без ролей нельзя ни применить процент цикла (он относится к рабочему подходу, а не к разминке),
ни построить динамику прогресса, ни сравнить упражнение с самим собой в прошлом.

Роли проставляются автоматически по **правилу пика**: максимальный вес и все подходы этого веса —
рабочие; всё до первого достижения пика — разминочные; всё после — добивающие. Атлет правит
результат одним касанием.

## Почему именно правило пика

Первая версия правила («лесенка вверх — разминка, дальше рабочее») ломалась на пирамидах вида
`10/12/14/16/16/14/12`, которые в реальных программах встречаются постоянно. Правило пика
проверено на всех доступных реальных неделях и дало верный разбор в каждом случае:

| Запись | Разбор |
|---|---|
| `20/30/40/50/60*6-8` | разминка 20–50, рабочий 60 |
| `10/12/14/16/16/14/12*6-8` | разминка 10–14, рабочие 16/16, добивающие 14/12 |
| `20/25/27,5/27,5/27,5/27,5*6-7` | разминка 20–25, рабочих четыре |
| `30+30*8` тремя строками | все три рабочие |

## Последствия

- Роль записывается вместе с данными. Задним числом восстановить её невозможно — если собрать
  данные без ролей, добивающие подходы навсегда испортят статистику и будут выглядеть регрессом.
- Отказной подход (`9*мах`) — именно роль подхода, а не тип упражнения и не тип прогрессии.
- Прогресс считается **только по рабочим подходам**.
