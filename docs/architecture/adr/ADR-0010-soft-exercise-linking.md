# Личное упражнение связывается с системным мягко; связь устанавливает только атлет

**Статус:** Принят  
**Дата:** 2026-09-06  

Справочник упражнений гибридный: глобальная часть заводится вручную разработчиком и содержит
профессиональные названия, личная часть заводится атлетом, когда он не знает канонического
названия станка. Личное упражнение можно **связать** с системным — после этого история
участвует в общей статистике по каноническому упражнению.

Два ограничения, которые важнее самого механизма:

**Связь мягкая.** Личное упражнение не удаляется и не сливается физически. Связь можно
переустановить в отдельном разделе — новичок легко ошибается («Тяга Т-грифа» и «Горизонтальная
тяга рычажная» кажутся ему одним движением), а необратимое слияние истории исправить нечем.

**Связывает только сам атлет.** Ни система, ни кто-либо другой не связывает за него: иначе
названия упражнений в его дневнике менялись бы без его ведома.

**Связанное упражнение для атлета — одно упражнение с системным.** История, МПВ, тип прибавки,
подбор веса и подсказки у них общие; атлет видит своё название. Переустановка связи переносит
историю личного упражнения к новому системному. Записи сохраняют исходное выбранное
упражнение: созданное напрямую через системное остаётся у него, даже если на момент записи
к нему было привязано личное. Это позволяет исправить ошибочную связь, сохранив правильно
записанные выполнения другого упражнения.

При объединении МПВ определяется общей хронологией допустимых проходок и пересмотров:
без пересмотров это лучший из двух МПВ. Простое сравнение максимумов недопустимо, если
старый рекорд отменил бы поздний сознательный пересмотр. При разделении МПВ каждой истории
пересчитывается по оставшимся источникам; уменьшение из-за исправленной связи не считается
регрессом. Пересмотр сохраняет принадлежность выбранному при нём упражнению.

По расходящимся текущим настройкам — шаг оборудования, комментарий, тип прибавки,
тип упражнения, признак подбора веса — система **один раз спрашивает атлета**, какое значение
оставить. При разделении текущие общие значения предлагаются обеим историям с возможностью
явной правки: скрытого отката к старым настройкам нет. Счётчик снятия подбора начинается
заново при изменении состава истории. Исторические признаки выполнений сохраняются,
а созданные циклы не получают другие веса молча. Точные правила и пример —
[exercise-catalog](../../requirements/exercise-catalog/index.md), R5.2–R5.7.

**Системное упражнение используется напрямую.** Выбрав его в подсказке, атлет получает
в тренировке само системное упражнение, а не свою копию. Всё личное хранится у пары
(атлет, упражнение), где упражнение может быть и системным, и личным.

## Считанные альтернативы

- **Физическое слияние** личного упражнения с системным. Отвергнуто: новичок легко ошибается
  со связью, а слитую историю не разделить обратно.
- **Автоматическое сопоставление** по похожести названия. Отвергнуто: цена ошибки выше выгоды,
  и названия в дневнике менялись бы без ведома атлета.
- **Связанное личное и системное — два упражнения с двумя историями.** Отвергнуто: связь для того
  и ставится, чтобы сказать «это одно и то же движение». Атлет, связавший «тот тренажёр для спины»
  с «Тягой верхнего блока», а потом выбравший в подсказке саму тягу, начал бы вторую историю.
- **При связывании молча выбрать настройки** одной из сторон. Отвергнуто: любая сторона могла быть
  выставлена атлетом сознательно.
- **Личная копия системного упражнения при каждом выборе.** Отвергнуто: у каждого атлета
  появились бы дубли справочника, а связь пришлось бы ставить заново для упражнения, которое
  и так системное.
- **При исправлении связи переносить всю общую историю.** Отвергнуто: прямые записи
  системного упражнения могли быть правильными; исправление личного названия не должно
  присваивать их другому упражнению.
- **После разделения скрыто вернуть прежние настройки.** Отвергнуто: значения могли
  сознательно измениться во время общей истории; атлет подтверждает текущие значения
  или правит их явно.

## Последствия

- Атлет видит **своё** название, каноническое — подсказкой ниже, мельче и приглушённее.
  Это учит правильным названиям, не отнимая привычных.
- Нужен отдельный раздел управления связями — иначе ошибку исправить негде.
- Глобальный справочник **не пополняется** пользовательскими названиями автоматически: за месяц
  он превратился бы в свалку опечаток.
