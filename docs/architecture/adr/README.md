# ADR — записи о принятых решениях

Решение попадает сюда, когда верны **все три** условия:

1. **Трудно обратить** — цена смены мнения потом ощутима.
2. **Неочевидно без контекста** — будущий читатель спросит «почему это сделано так?».
3. **Был реальный выбор** — существовали альтернативы, и мы выбрали одну по конкретным причинам.

Если хотя бы одно не выполняется, ADR не пишется: обратимое решение просто обратят, очевидное
никого не удивит, а безальтернативное нечего записывать.

На этом этапе фиксируются **только продуктовые и доменные решения**. Технологические
(база данных, ORM, хостинг, схема аутентификации) будут записаны, когда действительно будут
приняты — вместе с PRD, а не задним числом.

| № | Решение | Затрагивает |
|---|---|---|
| [0001](./ADR-0001-cycle-over-plan.md) | Соблюдение цикла важнее выполнения плана на неделю и тренировку | Главный экран, все метрики |
| [0002](./ADR-0002-overperformance-is-negative.md) | Перевыполнение плана помечается как негативное | Выполнение тренировки, метрики |

| [0004](./ADR-0004-max-is-actual-weight.md) | МПВ — фактически поднятый вес; при провале проходки не понижается автоматически | МПВ, проходка, цикл |
| [0005](./ADR-0005-progression-belongs-to-exercise.md) | Тип прибавки принадлежит паре (атлет, упражнение), а не шаблону цикла | Цикл, прогрессия, модель данных |
| [0006](./ADR-0006-structured-plan-not-text.md) | План хранится структурно; нотация — только формат ввода | Вся модель данных |
| [0007](./ADR-0007-set-roles-peak-rule.md) | У подхода есть роль; определяется правилом пика | Ввод, выполнение, статистика |

| [0011](./ADR-0011-machine-weights-not-comparable.md) | Веса на тренажёрах несопоставимы между залами; два режима аналитики | Залы, МПВ, аналитика |
| [0012](./ADR-0012-coach-is-permission-not-role.md) | Тренер — право доступа, а не роль | Модель пользователей, доступ |
| [0013](./ADR-0013-mobile-only-design-target.md) | Мобильный браузер — единственный проектный ориентир | Все интерфейсы |
| [0014](./ADR-0014-not-every-cycle-targets-growth.md) | Не каждый цикл нацелен на рост: развивающий и поддерживающий | Цикл, метрики, МПВ |

Нумерация сквозная, по возрастанию. Отменённое решение не удаляется — вместо этого пишется
новый ADR, а в старом ставится пометка о том, чем он заменён.
