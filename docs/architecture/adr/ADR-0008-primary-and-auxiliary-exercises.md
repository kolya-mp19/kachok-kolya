# Упражнения делятся на основные и вспомогательные

**Основные** упражнения определяют прогресс: они участвуют в цикле, имеют МПВ и попадают
в статистику. **Вспомогательные** обслуживают основные — подводка, добивка, работа без
назначенного веса, работа по времени. Они отмечаются выполненными, но в динамику прогресса
и в точность плана не входят.

Деление введено вместо более раннего замысла «третий тип прогрессии для упражнений без веса».
Оно точнее ложится на реальность: фронтальный присед перед приседом со страховочным грифом —
это не отдельная дисциплина со своим прогрессом, а подводка к основному движению.

## Что это решает

- Упражнения без планового веса перестают выглядеть как «упражнение с незаполненным планом»,
  на которое продукт должен ругаться.
- Упражнения по времени («разогрев 5–7 мин») выражаются без спецмеханик — через единицу
  измерения упражнения.
- Атлет видит, какие 3–5 упражнений недели реально определяют его прогресс, а какие их
  обслуживают. Это прямо служит систематизации (П1).

## Последствия

- Единица измерения (кг, кг на сторону, минуты, без отягощения) — свойство упражнения
  в справочнике, а не поля подхода.
- Термины «целевое упражнение» и «прогрессия по самочувствию» из ранних черновиков отменены
  и в продукте не употребляются.
