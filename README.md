# Kachok Kolya

Приложение для планирования и отслеживания силовых тренировок: цикл с проходкой, быстрый ввод
недели нотацией, запись факта по подходам, динамика МПВ. Отдельно — анонимный калькулятор
коэффициентов относительной силы.

Сейчас в репозитории — бизнес-документация и чистый каркас Next.js; код фич ещё не написан.

## Документация

Начинать с [`docs/README.md`](docs/README.md): порядок чтения, принципы, глоссарии, спеки фич,
ADR и отложенное.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).
