# Kachok Kolya

Приложение для планирования и отслеживания силовых тренировок: цикл с проходкой, быстрый ввод
недели нотацией, запись факта по подходам, динамика МПВ. Отдельно — анонимный калькулятор
коэффициентов относительной силы.

Дневник предназначен для регулярно тренирующихся атлетов, прежде всего пауэрлифтеров.
Первая проходка в итогах завершённого цикла устанавливает исходный МПВ по каждому основному
упражнению. От него приложение подсказывает веса следующих развивающих циклов и цель следующей проходки
с учётом выбранной атлетом прибавки. Атлет составляет план, отмечает факт выполнения
и в итогах следующего завершённого цикла получает новый МПВ, если в его проходке поднял больший
вес. Подсказки помогают последовательно планировать рост МПВ, но не гарантируют прибавку в каждом цикле.

Калькулятор работает отдельно от дневника: сравнивает результаты в строгом подъёме
на бицепс по собственному весу и лучшей попытке спортсмена.

Сейчас в репозитории — только документация. Реализация ещё не начата; стартового проекта, исходного кода приложения и зависимостей нет.
