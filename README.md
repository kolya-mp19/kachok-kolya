# Kachok Kolya

Приложение для планирования и отслеживания силовых тренировок: цикл с проходкой, быстрый ввод
недели нотацией, запись факта по подходам, динамика МПВ. Отдельно — анонимный калькулятор
коэффициентов относительной силы.

Сейчас в репозитории — только документация. Реализация ещё не начата; стартового проекта, исходного кода приложения и зависимостей нет.
