# Инструкции для агентов

Текущая цель — готовое приложение, работающее локально по согласованному стеку.
Разрешены локальная реализация всех продуктовых сценариев и необходимые зависимости
без ожидания E003/S01. Для регистрации, подтверждения почты и восстановления доступа
используется SMTP-перехватчик Mailpit в Docker с локальным веб-интерфейсом писем.
Внешняя почта, Яндекс/VK, удалённая инфраструктура, деплой и выпуск отложены и не разрешены.
Их задачи не блокируют локальную разработку и приёмку; E003/S01 и внешние части других
эпиков не объявляются завершёнными на основании локальной готовности.

Начинайте чтение с [docs/README.md](docs/README.md). Соблюдайте описанные там правила
документации, используйте канонические термины из глоссариев и учитывайте принятые ADR.

Перед написанием или изменением кода прочитайте
[общие соглашения о коде](docs/architecture/coding-conventions.md), затем применимое
руководство: [бэкенд NestJS/Prisma](docs/architecture/backend-conventions.md) или
[фронтенд React](docs/architecture/frontend-conventions.md). При изменении контракта API
прочитайте оба. Эти документы обязательны для нового и изменяемого кода и содержат
все необходимые примеры; наличие других проектов на компьютере не требуется.
Текущие длинные фабрики и сжатые однострочные блоки не являются образцом для продолжения.

Комментируйте причины неочевидных решений, защитных проверок, исключений и порядка
операций. Для неочевидных публичных контрактов используйте JSDoc; для локальных причин —
комментарий рядом с проверкой. Не пересказывайте код. При изменении поведения обновляйте
объяснение вместе с реализацией. Подробные требования и примеры находятся
в [правилах комментариев](docs/architecture/coding-conventions.md#комментарии-и-jsdoc).

Не совмещайте функциональную задачу с массовым рефакторингом. При изменении существующего
кода приводите затронутую логику к соглашениям, сохраняя поведение и гарантии доступа,
транзакций, повторов и сохранности черновиков. Для самостоятельного рефакторинга
сначала определите границы изменения и проверки поведения.
