# Инструкции для агентов

Разрешена локальная реализация E004 по согласованному стеку до завершения E003.
Создание хранения, внешних интеграций, инфраструктуры и выпуск требуют своего запроса
и выполнения зависимостей; блокеры E003 сохраняются.

Начинайте чтение с [docs/README.md](docs/README.md). Соблюдайте описанные там правила
документации, используйте канонические термины из глоссариев и учитывайте принятые ADR.
