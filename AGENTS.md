# Инструкции для агентов

Разрешена локальная реализация E004 и E005 по согласованному стеку до завершения E003,
включая локальное хранение и необходимые зависимости E005. Внешние интеграции,
создание удалённой инфраструктуры и выпуск не разрешены. Блокер внешних доступов
E003 сохраняется; E003 и S01 не объявляются завершёнными по этому исключению.

Начинайте чтение с [docs/README.md](docs/README.md). Соблюдайте описанные там правила
документации, используйте канонические термины из глоссариев и учитывайте принятые ADR.
